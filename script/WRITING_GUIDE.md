# 대본 집필 가이드 (모든 화 공통)

견본: `script/part1/ep01.md` — 반드시 먼저 읽고 형식·밀도·톤을 그대로 맞출 것.
설정: `plan/00_series_bible.md`, `plan/0N_partN.md`

## 파일
- 경로: `script/partN/epXX.md` (XX = 01~15, 두 자리)
- 각 부 폴더에 `script/partN/CONTINUITY.md` (연속성 메모)를 두고, 한 화를 마칠 때마다 갱신한다:
  새로 등장한 인물(이름·읽기·나이·말투), 확정된 사실, 회수해야 할 복선, 다음 화로 넘긴 훅.

## 형식 (견본과 동일)
1. 제목: `# 第N部 『부 제목』 第X話 「화 제목」（한국어 제목）`
2. 정보 표: 턴 수 / 등장인물 / 구성(7구간과 턴 범위)
3. 필요하면 `> 등장인물 관계 메모:` 한두 줄
4. 본문: `## ① 콜드 오픈` … `## ⑦ 엔딩 훅`, 구간 사이에 `---`
5. 장면 표시: `【場面：장소／시간】`
6. 대사: `NNN 話者：台詞` (NNN = 001~150, 세 자리, 한 줄에 한 턴, 빠짐·중복 없이 정확히 150턴)
   - 화자 표기는 성(鷹見·真壁·東堂·柚木·七瀬·久我·神崎 등) 또는 역할(警官、若者A 등)
   - 지문·내레이션은 쓰지 않는다. 행동은 대사 속에서 드러낸다.
7. 마지막에 `## 어휘·표현 노트` (표, 15~20개, 한국어 설명) + `### 말투 포인트` (4~6개 불릿)

## 150턴 7구간 (대략, ±5턴 조정 가능)
① 콜드 오픈 1–12 / ② 편집회의·상황 정리 13–30 / ③ 취재 31–60 / ④ 전개·잠입 61–95 / ⑤ 반전 96–120 / ⑥ 클라이맥스 121–142 / ⑦ 엔딩 훅 143–150
- 장면 성격상 「편집회의」가 맞지 않는 화는 같은 기능(정보 정리·역할 분담)을 하는 다른 장면으로 대체해도 된다.
- 마지막 턴(150)은 질문이나 충격으로 끝내 다음 화로 이어지게 한다.

## 내용 원칙
- 해당 부 기획서의 그 화 줄거리를 충실히 따르되, 대화로 구체화하면서 디테일(숫자, 지명, 서류 이름, 수법)을 채운다.
- 앞 화의 엔딩 훅을 다음 화 콜드 오픈에서 받는다.
- 일본어는 자연스러운 현대 일본어. 인물별 말투(바이블 참조)와 경어 수준 차이, 업계 은어, 지역 방언을 살린다.
- 실존 인물·실존 기업·실존 단체 이름은 쓰지 않는다(가공 이름만). 실제 제도·법률·지명은 써도 된다.
- 폭력·범죄 수법은 극에 필요한 수준으로만 묘사하고, 실제로 따라 할 수 있는 구체적 절차는 쓰지 않는다.
- 각 화 길이: 본문 대사 약 6,000~9,000자.

## 검증 (각 화 저장 후 반드시 실행)
```bash
f=script/partN/epXX.md; grep -cE '^[0-9]{3} ' $f; grep -oE '^[0-9]{3}' $f | awk '{if($1+0!=NR){print "gap at",NR; exit}}'
```
첫 줄이 150이고 gap 출력이 없어야 한다.
