# 第8部 『真実の代償』（진실의 대가）

## 개요
| 항목 | 내용 |
|---|---|
| 모티브 | 국가정보국 신설·スパイ防止法 입법 논의와 인권·보도의 자유 우려, 정보기관의 기자·야당 감시 의혹, 오사카 IR(카지노) 관련 해외기업 뇌물 사건과 2030년 개업 준비, 세계 보도자유 순위에서의 일본 하위권, 기자클럽 체제 |
| 테마 | 「知る権利」 ― 진실을 말하는 대가를 누가 치르는가 |
| 메인 빌런 | **氷室 恭一** (오메가 대표), 내각관방 부장관 **西園寺 匡**(68) |
| 게스트 | 오메가 전 직원 **雨宮 玲奈**(33), 「東都新聞」 정치부장 **野々村 修**, 한국 기자 **尹 瑞珍**, 대만 기자 **林 美玲**, 국제 기자단체 대표 |
| 진실의 공개 | 1~7부 모든 사건을 잇는 오메가의 「顧客台帳」 |
| 핵심 어휘 | 国家情報局、スパイ防止法、監視、秘密保護、特定秘密漏洩、報道の自由、知る権利、取材源の秘匿、記者クラブ、IR、統合型リゾート、贈賄、証人喚問、国政調査権 |
| 방언 | 오사카 사투리(4~5화) |
