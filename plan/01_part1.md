# 第1部 『闇の求人』（어둠의 구인）

## 개요
| 항목 | 내용 |
|---|---|
| 모티브 | 2024~25년 수도권 연속 闇バイト 강도, トクリュウ(匿名・流動型犯罪グループ), 캄보디아·미얀마 특수사기 거점과 일본인 감금, SNS 투자사기 광고, 증권계좌 탈취, 명부 유출 |
| 테마 | 「使い捨てにされる若者」 ― 거리의 범죄는 누구의 돈이 되는가 |
| 메인 빌런 | 指示役 「キング」 = **榊原 蓮**（さかきばら れん, 29）, 전 핀테크 스타트업 CEO |
| 게스트 | 실행역 청년 **森 悠斗**(19), 피해자 유족 **佐伯 和子**(68), 경비회사 사장(전 경찰간부) **梶 達郎**(61) |
| 시리즈 훅 | 범죄수익이 국회의원 비서의 계좌를 거쳐 「オメガ」의 컨설팅비로 지급된 흔적 |
| 핵심 어휘 | 闇バイト、ホワイト案件、タタキ、受け子、出し子、掛け子、指示役、リクルーター、テレグラム、秘匿アプリ、名簿屋、口座売買、暗号資産、ミキサー |
