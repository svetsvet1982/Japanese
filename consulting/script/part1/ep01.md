> 설정 메모: 松葉屋는 1866년 창업한 日本橋의 노포 백화점. 매출 약 2,800억 엔, 3기 연속 영업적자. 日本橋 본점 외에 지방점 5곳(宇都宮·高崎·水戸·甲府·沼津).

## ① 콜드 오픈

【場面：丸の内・グレイストーン・パートナーズ　三十二階エレベーターホール／午後】

001 朝倉：失礼いたします。松葉屋の松永社長でいらっしゃいますね。下まで、ご一緒させてください。
002 松永：……グレイストーンの方か。一条さんには、たった今お断りを申し上げたところだが。
003 朝倉：存じております。マネージャーの朝倉と申します。一階に着くまでの三十秒だけ、いただけませんか。
004 松永：三十秒で、何が言える。
005 朝倉：結論から申し上げます。地方の五店舗は、閉じるべきです。ただし、閉じ方を間違えると、日本橋の本店も一緒に沈みます。
006 松永：……他社も同じことを言ったよ。地方店を閉めろ、と。
007 朝倉：ヴァンテージさんは「どの店を閉めるか」をご提案なさったはずです。私どもがお答えしたいのは、「閉めたあと、誰が松葉屋に残るのか」です。店ではなく、お客様のお話をさせてください。
008 松永：（階数表示を見上げて）……あと十階か。
009 朝倉：百六十年、松葉屋でお買い物をなさってきたお客様が、地方店がなくなった翌日、どこで何をお買いになるのか。その答えを持たない再生計画は、数字の上でしか成功しません。
010 松永：……朝倉さん、と言ったね。明日の朝九時、日本橋の本店に来なさい。一条さんには、私から電話を入れておく。

## ② 팀 미팅

【場面：グレイストーン・パートナーズ　プロジェクトルーム／同日夕方】

011 一条：朝倉。断られた案件を、エレベーターでひっくり返したそうだな。
012 朝倉：差し出がましい真似をいたしました。申し訳ありません。
013 一条：謝るな。取ったんだから、それでいい。……ただし、取った以上は三か月で結果を出せ。松葉屋は小売業界への入口だ。ここで失敗したら、次はない。
014 朝倉：承知しています。
015 一条：チームは芹沢と、今日入った新人をつける。……小野寺くん、入りなさい。
016 小野寺：し、失礼いたします！　本日付で配属になりました、アナリストの小野寺健太と申します！　至らない点ばかりかと存じますが、何卒よろしくお願い申し上げます！
017 芹沢：……声、大きい。ここ、会議室だから。
018 小野寺：す、すみません！
019 芹沢：シニアコンサルタントの芹沢です。よろしく。
020 一条：あとは任せる。朝倉、明日の初回訪問が終わったら報告をくれ。
021 朝倉：はい。……さて、始めよう。小野寺くん、松葉屋について知っていることは？
022 小野寺：はい！　えっと、創業百六十年の老舗百貨店で、日本橋本店のほかに地方店が五つ……売上高は約二千八百億円、三期連続の営業赤字で……あと、インバウンドの売上が本店の三割を超えている、と昨日ネットの記事で……。
023 朝倉：十分だ。じゃあ、この案件の「イシュー」は何だと思う？
024 小野寺：イシュー……「どうすれば黒字になるか」、でしょうか。
025 芹沢：それは願望。イシューじゃない。
026 朝倉：芹沢、言い方。……でも、その通りだ。イシューというのは、答えを出すべき問いの中で、一番インパクトが大きくて、しかも答えが出せるものだ。今回なら「地方五店舗を閉じたとき、松葉屋の売上とお客様の何が残るか」。ここに答えが出れば、残りの論点はほとんど決まる。
027 芹沢：初期仮説は全店閉鎖ね。エレベーターで社長に言ったとおり。
028 朝倉：ああ。仮説は外れていい。外れたら捨てればいい。分担を決めよう。芹沢は店舗別の損益と閉店コストの試算。小野寺くんはPOSデータの整理。俺は明日、経営陣のヒアリングだ。

## ③ 클라이언트·현장

【場面：日本橋・松葉屋本店　社長室／翌朝九時】

029 松永：来たね。紹介しよう。経営企画部長の堀田と、外商部長の沢村だ。
030 堀田：堀田でございます。……正直に申し上げますと、コンサルタントの方とお仕事をするのは三度目でして。前の二社の報告書は、あちらの棚で眠っております。
031 朝倉：拝見してもよろしいですか。
032 堀田：どうぞ。どちらも結論は「地方店の閉鎖」でした。実行されたことは、一度もございませんが。
033 芹沢：実行されなかった理由を、伺ってもよろしいですか。
034 堀田：それは……。（社長の顔をうかがう）
035 松永：私が決めなかったからだ。遠慮しなくていい。
036 沢村：社長、それは違います。お決めになれなかったのは、お客様のお顔が見えていたからでございましょう。
037 朝倉：沢村部長。「お客様のお顔」というのは。
038 沢村：外商は、お客様のお宅に伺ってお品物をお届けする部署でございます。宇都宮にも高崎にも、三代続けてお付き合いいただいているお家がございます。店を閉めるというのは、そのお家に「もう参りません」と申し上げることなのです。
039 朝倉：お気持ちは理解できます。ただ、お気持ちだけでは、赤字は埋まりません。
040 沢村：……。
041 松永：朝倉さん、まず売り場を見ていきなさい。数字の前に、この店の空気を吸ってから話をしてほしい。

【場面：本店一階　ラグジュアリーブランド売り場】

042 小野寺：うわ……平日の午前中なのに、すごい人ですね。ほとんど海外のお客さんだ。
043 堀田：本店の一階と二階の売上は、半分近くが免税売上です。円安のおかげで、ここ数年はどうにか息をつけました。
044 芹沢：「おかげで」ということは、円高に振れたら。
045 堀田：……ええ。一円円高になるたびに、本店の利益が数億円単位で消えます。正直なところ、薄氷の上に立っているようなものです。
046 朝倉：地方店の免税売上は。
047 堀田：ほぼゼロです。地方店のお客様は、ほとんどが地元のご年配の方で……売上はこの十年で、およそ四割減りました。
048 小野寺：（小声で）朝倉さん、あの……メモ、取っていいですか。
049 朝倉：取らなくていいことは、ひとつもない。

【場面：本店七階　外商サロン】

050 沢村：こちらが外商サロンでございます。お得意様が、ご予約のうえでお買い物をなさる場所です。
051 芹沢：外商の売上は、どこの店に計上されているんですか。
052 沢村：お客様の担当が本店の外商員であれば、本店でございます。地方店にも外商員はおりますが、大きなお取引ほど、本店の担当がお伺いすることが多うございます。
053 芹沢：……なるほど。
054 朝倉：沢村部長、外商のお客様の名簿と、過去五年分の取引データをお借りできますか。
055 沢村：お客様の大切な情報でございます。社長のご許可があれば、ですが……。私どものお客様を、数字のひとつとしてお扱いになるのでしたら、お断りいたします。

## ④ 분석·검증

【場面：グレイストーン・パートナーズ　プロジェクトルーム／三日後】

056 朝倉：外商データは、社長の決裁が下りた。……沢村部長は、最後まで渋い顔だったけどな。
057 芹沢：店舗別損益、まとまった。見て。
058 朝倉：……地方五店舗の合計で、営業赤字が年間六十二億円。
059 芹沢：本店の営業利益が四十億だから、地方店が本店の稼ぎを全部食べて、さらに二十億以上のマイナス。三期連続赤字の正体は、これ。
060 小野寺：閉店のコストって、どれくらいかかるんですか？
061 芹沢：建物の賃貸借契約の解約違約金、原状回復、従業員の退職金と再配置、それに減損。ざっと見積もって、五店舗で百八十億。
062 小野寺：ひゃ、百八十億……。
063 芹沢：でも、毎年六十億の赤字が消えるなら、三年で回収できる。数字だけなら、閉めない理由はない。
064 朝倉：前の二社も、同じ計算をしたんだろうな。
065 芹沢：たぶんね。それで、社長が決めなかった。
066 朝倉：そこが問題なんだ。正しい答えが二回出て、二回とも実行されなかった。だったら三回目の俺たちが同じ答えを出しても、棚の報告書が一冊増えるだけだ。
067 小野寺：じゃあ、どうするんですか？
068 朝倉：答えは同じでもいい。違うのは、社長が「決められる」形で持っていくことだ。……小野寺くん、POSデータはどうだ。
069 小野寺：あ、はい。えっと……すみません、まだ途中で。データの形式が店ごとにバラバラで、商品コードの体系も地方店と本店で違うんです。今、変換テーブルを作っていて……。
070 芹沢：いつ終わる？
071 小野寺：あ、明日の……朝には。たぶん。
072 芹沢：「たぶん」はいらない。終わるか、終わらないか。
073 小野寺：……終わらせます。
074 朝倉：小野寺くん。データを整えるのは大事だが、目的を忘れるな。俺たちが知りたいのは「地方店を閉めたら、何が消えて、何が残るか」だ。全部をきれいにする必要はない。その問いに答えるのに必要なところだけでいい。
075 小野寺：……はい。必要なところだけ。
076 朝倉：芹沢、ステコミの資料は金曜までに骨子を固めたい。イシューツリーと初期仮説、それから検証計画。
077 芹沢：ステコミは来週の月曜だっけ。
078 朝倉：ああ。社長、堀田部長、沢村部長、それに労務担当の大森常務。初回だから、結論じゃなくて「どう考えるか」を合意する場だ。
079 芹沢：合意、取れると思う？
080 朝倉：取る。……取れる形にする。

## ⑤ 대립·벽

【場面：丸の内・オフィスビル一階ロビー／夜】

081 黒川：朝倉くん。久しぶりだね。
082 朝倉：黒川さん。……どうしてここに。
083 黒川：隣のビルで会食だよ。松葉屋、取ったんだってね。エレベーターで社長を口説いたと聞いた。
084 朝倉：お耳が早いですね。
085 黒川：うちが二か月かけて作った提案書を、三十秒でひっくり返されたんだ。噂にもなる。
086 朝倉：ヴァンテージさんの提案書は拝見していませんが、内容は正しかったと思いますよ。
087 黒川：知ってるよ。正しいから負けたんだ。……君は「閉め方」を売った。でも、あの社長が買ったのは、たぶん答えじゃない。「決断を先延ばしにしていい理由」だ。
088 朝倉：……どういう意味ですか。
089 黒川：老舗の社長というのはね、正しい答えを一番よく知っている人間なんだよ。知っていて、決めない。君の仕事は、彼に決めさせることだろう？　三か月後、君の報告書があの棚に並んでいないことを祈ってるよ。
090 朝倉：ご心配なく。棚には並べません。
091 黒川：いい返事だ。……じゃあ、また。どこかの案件で。

【場面：グレイストーン・パートナーズ　一条の部屋／同夜】

092 一条：黒川に会ったか。
093 朝倉：ロビーで。……嫌味を言われました。
094 一条：あいつの嫌味は、だいたい当たる。気をつけろ。……朝倉、ステコミの資料を見た。地方店は全店閉鎖で行くんだな。
095 朝倉：初期仮説としては、です。
096 一条：それでいい。早く結論を出して、閉鎖の実行支援まで取れ。PMOで月額三千万、半年は固い。
097 朝倉：一条さん、まだ検証が終わっていません。外商データの分析次第では……。
098 一条：検証は、結論を補強するためにやるものだ。ひっくり返すためにやるんじゃない。……いいか、クライアントが欲しいのは真実じゃない。安心だ。覚えておけ。
099 朝倉：……失礼します。
100 一条：朝倉。お前のそういう顔は、嫌いじゃない。だが、案件は取れ。それが俺たちの仕事だ。

## ⑥ 설득

【場面：松葉屋本店　役員会議室／翌週月曜　午前】

101 朝倉：本日はお時間をいただき、ありがとうございます。結論から申し上げます。本プロジェクトで答えを出すべき問いは、ひとつです。「地方五店舗を閉じたとき、松葉屋の売上とお客様の何が残るのか」。
102 堀田：店を閉めるかどうか、ではなく？
103 朝倉：閉めるかどうかの計算は、すでに二度なされています。あちらの棚に二冊ございました。どちらも、数字としては正しい。地方店の赤字は年間六十二億円、閉店費用は約百八十億円。三年で回収できます。
104 大森：それなら、なぜ三度目の調査が必要なのかね。
105 朝倉：正しい答えが、二度とも実行されなかったからです。実行されなかった理由は、計算が間違っていたからではありません。計算に入っていないものがあったからです。
106 松永：……入っていないもの、とは。
107 朝倉：沢村部長がおっしゃった「お客様のお顔」です。地方店を閉めた翌日、三代続けて松葉屋をご利用のお客様がどこへ行かれるのか。本店にいらしてくださるのか、他社に移られるのか、それとも百貨店でお買い物をなさること自体をおやめになるのか。前の二冊には、その答えがありませんでした。
108 沢村：……。
109 朝倉：ですので、私どもの初期仮説は「地方五店舗は閉鎖する」です。そのうえで、この二週間で検証するのは三点。第一に、地方店のお客様のうち、本店や外商でつなぎ止められる方がどれだけいらっしゃるか。第二に、それが本店の売上をどれだけ支えるか。第三に、円高に振れたとき、インバウンドに頼らずに本店が立っていられるか。
110 堀田：仮説が外れたら？
111 朝倉：捨てます。仮説は、外れるためにあります。外れたとわかれば、それもひとつの答えです。
112 松永：（長い沈黙のあと）……前の二社は、最初の会議で「答え」を持ってきた。君は「問い」を持ってきたわけだ。
113 朝倉：はい。社長にお決めいただくための問いです。
114 松永：いいだろう。二週間、やってみなさい。沢村くん、外商のデータは全部出してあげなさい。……ただし、朝倉さん。お客様を数字で切るなら、その数字の向こうにいる人のことも、ちゃんと見てきてもらうよ。

## ⑦ 엔딩 훅

【場面：グレイストーン・パートナーズ　プロジェクトルーム／同日深夜】

115 小野寺：朝倉さん！　まだいらっしゃいますか！
116 朝倉：どうした、こんな時間に。
117 小野寺：外商データとPOSを、顧客IDでつなげてみたんです。それで、本店の外商売上に計上されているお客様の住所を、地図に落としてみたら……。
118 芹沢：見せて。……これ、本当？
119 小野寺：はい、三回確認しました。本店外商の上位のお客様のうち、四割以上が、地方五店舗の商圏にお住まいなんです。普段のお買い物は地方店で、大きなお買い物だけ本店の外商で……。地方店を閉めたら、この方たちも……。
120 朝倉：……本店の売上も、一緒に消えるかもしれない、ってことか。俺たちの仮説は、最初から間違っていた……？

## 어휘·표현 노트

| 표현 | 읽기 | 의미 |
|---|---|---|
| 結論から申し上げます | けつろんからもうしあげます | 결론부터 말씀드리겠습니다 (컨설턴트의 정형구) |
| 差し出がましい | さしでがましい | 주제넘다, 나서다 |
| イシュー | | 답을 내야 할 핵심 질문(issue) |
| 初期仮説 | しょきかせつ | 초기 가설 |
| 外商 | がいしょう | 백화점의 방문 판매·우량고객 전담 부문 |
| 免税売上 | めんぜいうりあげ | 면세 매출 (방일 외국인 대상) |
| 薄氷の上に立つ | はくひょうのうえにたつ | 살얼음판 위에 서 있다 |
| 商圏 | しょうけん | 상권 |
| 減損 | げんそん | 감손(자산 가치 하락분의 손실 처리) |
| 原状回復 | げんじょうかいふく | (임차 건물의) 원상 복구 |
| ステコミ | | ステアリングコミッティ(운영위원회)의 줄임말 |
| イシューツリー | | 이슈를 하위 논점으로 분해한 나무 구조도 |
| PMO | | Project Management Office. 실행 지원 조직·업무 |
| 耳が早い | みみがはやい | 소식이 빠르다 |
| 渋い顔 | しぶいかお | 떨떠름한 표정 |
| 多うございます | おおうございます | 「多いです」의 아주 정중한 표현(노포 직원의 격식체) |

### 말투 포인트
- **朝倉**: 클라이언트에게는 「〜でいらっしゃいますね」「申し上げます」「拝見してもよろしいですか」 같은 존경어·겸양어. 팀 안에서는 「〜だ」「〜しよう」의 담백한 보통체.
- **芹沢**: 「それは願望。イシューじゃない」「『たぶん』はいらない」처럼 짧고 단정적인 말투.
- **小野寺**: 첫 인사의 과잉 경어(「至らない点ばかりかと存じますが、何卒〜」)와 「えっと」「すみません」「たぶん」의 잦은 사용. 신입다움의 표지.
- **沢村**: 「〜でございます」「〜なさる」「多うございます」 등 노포 백화점 외상 부장의 고풍스러운 접객 경어.
- **一条**: 부하에게 「〜しろ」「〜するな」의 명령형. 「クライアントが欲しいのは真実じゃない。安心だ」는 시리즈에 걸친 그의 신조.
- **黒川**: 「〜だね」「〜だよ」의 부드러운 말투 속에 날카로운 비꼼을 담는다.
