# 《角の家（かどのいえ）》 일본어 연속 대화문 기획서

네덜란드어 기획서 《Het Hoekhuis》의 구조(5부 × 18화 × 120턴, 계절 순환 군상극, 난이도 상승, 한글 해석·낭독 포인트)를 그대로 따르되,
**도쿄 스미다구 下町의 모퉁이 4층 건물**을 무대로 옮기고 **2024~2026년 일본의 실제 사회 현안**을 반영한 일본어판.

- 파일: `角の家_일본어_연속대화문_기획서.xlsx`
- 시트: 개요 / 진행 현황 / 등장인물 / 난이도 설계(JLPT N4~N1) / 화별 개요(90화, 시기·반영 현안 열 추가) / 반영 현안 / 문체 원칙 / 부별 어휘 영역 / 소재별 배치
- 시기: 2026년 3월 ~ 2027년 5월
- 큰 줄기: 대가 별세 → 상속인의 건물 매각 → 투자회사의 퇴거 압박 → 입주민 合同会社로 건물 매입
