# 《角の家》 第1部 春 第02話 「自転車が消えた」（자전거가 사라졌다）

| 항목 | 내용 |

| 등장인물 | リク(中村陸, 10), イサオ(角野功, 58), ラン(中村ラン, 40), 警官(交番の巡査) |

## 본문

【場面：喫茶かどっこ／土曜日、朝9時】

リク：イサオさん！　イサオさん！
イサオ：おう、リク。おはよう。どうした、そんなに走って。
リク：ぼくの自転車が、ないんです！
イサオ：自転車？　どこに置いた？
リク：ビルの前の駐輪場(ちゅうりんじょう)です。いつもの場所。
イサオ：いつ置いたんだ。
リク：昨日の夕方です。五時ごろ、サッカーから帰ってきて、置きました。
イサオ：鍵(かぎ)は？　ちゃんとかけたか？
リク：かけました！　……たぶん。
イサオ：たぶん、か。
リク：いや、かけました。絶対かけました。カチッて音がしましたから。
イサオ：分かった分かった。落ち着け。お母さんは？
リク：もう仕事に行きました。今日は朝七時からなんです。
イサオ：そうか。ランさん、土曜も早いんだな。
リク：どうしよう……。あれ、新しい自転車なんです。先月、おばあちゃんが買ってくれたんです。
イサオ：青いやつだろ。かっこいいって、自慢(じまん)してたもんな。
リク：はい……。今日、十時からサッカーの練習があるのに。
イサオ：練習は休め。まず、一緒に探そう。
イサオ：「準備中」の札(ふだ)をかけて、と。よし、行くぞ。

【場面：ビルの前の駐輪場／朝9時10分】

イサオ：ここか。
リク：はい。ここに置いてありました。この柱(はしら)の横です。
イサオ：ほかの自転車はあるな。ダイチくんのも、マリのも。
リク：ぼくのだけ、ないんです。
イサオ：何か落ちてないか？　鍵とか、部品とか。
リク：うーん……。何もないです。
イサオ：ちょっと周り(まわり)も見てみよう。誰かが乗って、どこかに置いたかもしれない。
リク：ビルの裏(うら)も見ます！
イサオ：おう。おれは角(かど)の向こうを見る。
リク：……ないです。裏には、古い自転車が一台あるだけです。
イサオ：こっちもない。コンビニの前にも、なかった。
リク：やっぱり、盗まれ(ぬすまれ)たんだ……。
イサオ：泣くな、リク。交番(こうばん)に届け(とどけ)を出そう。
リク：交番？　警察ですか？
イサオ：そう。自転車がなくなったら、交番に行くんだよ。見つかることも多いんだ。
リク：でも、何を言えばいいんですか。
イサオ：おまわりさんが聞いてくれるから、大丈夫。あ、お母さんに電話しておけ。
リク：はい。……もしもし、お母さん？　ぼく、リク。
ラン：リク？　どうしたの？　お母さん、今、仕事中よ。
リク：ごめん。自転車が、なくなっちゃったの。
ラン：えっ、あの新しいの？
リク：うん。今からイサオさんと交番に行く。
ラン：イサオさんが一緒なの？　ちょっと代わって。
イサオ：もしもし、ランさん。角野です。
ラン：イサオさん、すみません、ご迷惑(めいわく)をおかけして。
イサオ：いいんですよ。交番に行ってきます。防犯登録(ぼうはんとうろく)の番号、分かりますか。
ラン：ええと……家の引き出しに、カードがあります。お昼に休みがあるので、交番に持っていきます。
イサオ：分かりました。じゃあ、先に話をしておきます。

【場面：押上の交番／朝9時40分】

警官：はい、どうしましたか。
イサオ：すみません。この子の自転車が、なくなりまして。
警官：盗難(とうなん)ですね。君の自転車？
リク：はい。ぼくのです。
警官：名前を教えてくれるかな。
リク：中村陸です。十歳です。小学五年生です。
警官：中村陸くんね。こちらの方は、お父さん？
イサオ：いいえ、同じビルに住んでいる者です。一階で喫茶店をやっています。
警官：そうですか。保護者の方は？
イサオ：お母さんが仕事中で、お昼にここに来るそうです。
警官：分かりました。では、陸くん。いくつか質問するね。
リク：はい。
警官：自転車をどこに置きましたか。
リク：家のビルの前の駐輪場です。京島(きょうじま)の角のビルです。
警官：いつ置きましたか。
リク：昨日の夕方、五時ごろです。
警官：なくなったのに気づいたのは、いつ？
リク：今日の朝、九時ちょっと前です。
警官：じゃあ、昨日の五時から、今日の九時までの間だね。
リク：はい。
警官：鍵はかけていましたか。
リク：かけていました。前の車輪(しゃりん)の鍵です。
警官：チェーンの鍵は？
リク：チェーンは……つけていませんでした。
警官：そうか。今度からは、鍵を二つつけるといいよ。「ツーロック」っていうんだ。
リク：はい……。
警官：自転車の色と形を教えてください。
リク：青です。タイヤが二十四インチで、前にかごがついています。
警官：ほかに何か、特徴(とくちょう)はある？
リク：ハンドルに、サッカーボールのシールを貼っています。
警官：いいね。それは分かりやすい。メーカーは分かる？
リク：うーん……、分かりません。
イサオ：たしか、白い字で何か書いてありましたが、覚えていません。
警官：大丈夫ですよ。防犯登録の番号があれば、すぐに調べられます。
イサオ：その番号は、お母さんがカードを持ってきます。
警官：では、お母さんがいらっしゃったら、被害届(ひがいとどけ)を作りましょう。
イサオ：見つかりますかね。
警官：自転車は、駅の近くに乗り捨て(のりすて)られていることがよくあります。放置自転車(ほうちじてんしゃ)として、区の保管所(ほかんじょ)に運ばれることもあります。
リク：保管所？
警官：区が、道にある自転車を集めて置いておく場所だよ。番号が分かれば、連絡が来るんだ。
リク：じゃあ、見つかるかもしれないんですね。
警官：かもしれない。あきらめないで待ってみよう。

【場面：押上の交番／お昼12時15分】

ラン：すみません、遅くなりました！　中村陸の母です。
警官：お疲れさまです。カードはお持ちですか。
ラン：はい、これです。防犯登録のカード。
警官：ありがとうございます。……はい、番号を確認しました。では、こちらの紙に、お名前と住所と電話番号をお願いします。
ラン：はい。……書きました。
警官：これで被害届を受け付けました。何か分かったら、お電話します。
ラン：よろしくお願いします。
リク：お母さん、ごめんね。チェーンの鍵、つけてなかった。
ラン：……いいのよ。悪いのは盗んだ人。リクじゃない。
リク：でも、おばあちゃんに何て言えばいい？
ラン：正直(しょうじき)に言えばいいの。おばあちゃんは怒らないよ。
イサオ：そうだよ。ホアさんは、そんなことで怒る人じゃない。
ラン：イサオさん、本当にありがとうございました。お店まで休ませてしまって。
リク：イサオさん、ありがとうございました。
イサオ：おう。ほら、帰って、ナポリタンでも食べるか。

【場面：喫茶かどっこ／日曜日、午後3時】

リク：イサオさん！　見つかりました！
イサオ：おお、本当か！
ラン：さっき、交番から電話があったんです。押上駅の近くに置いてあったそうです。
リク：区の保管所に運ばれる前に、おまわりさんが見つけてくれたんです！
イサオ：よかったなあ。壊れてないか？
ラン：前のかごが少し曲がっていますけど、乗れるそうです。
リク：シールも、ちゃんと貼ってありました！
イサオ：シールのおかげだな。
リク：あとで、ダイチさんにかごを直してもらいます。
イサオ：それがいい。それから？
リク：それから……チェーンの鍵を買います。鍵を二つ。ツーロックです！
ラン：もう覚えたのね。
イサオ：えらいぞ、リク。でも、誰が乗っていったんだろうな。
リク：分かりません。でも……おまわりさんが言ってました。最近、このへんで自転車がたくさん盗まれているって。
イサオ：たくさん？　うちのビルの前でもか？
ラン：……私、ちょっと心配です。昨日の夜、駐輪場で知らない人を見た気がするんです。

## 낭독 포인트

- **촉음**: 「カチッて」「ちょっと」「乗っていった」「なくなっちゃった」 — 「っ」 앞에서 숨을 한 박 멈춘다.
- **장음 vs 단음**: 「交番(こうばん)」「保管所(ほかんじょ)」「放置(ほうち)」「防犯(ぼうはん)」 — 「こう」「ほう」「ぼう」를 두 박으로 길게. 「保管(ほかん)」은 짧게.
- **요음**: 「駐輪場(ちゅうりんじょう)」「自転車(じてんしゃ)」「車輪(しゃりん)」 — 「ちゅ」「じょ」「しゃ」를 한 박으로.
- **〜ています/〜ていました 축약**: 정중한 장면(경찰관 앞)에서는 「かけていました」를 또박또박, 집에서는 「つけてなかった」「言ってました」처럼 「い」 탈락.
- **불안한 억양**: 리쿠의 「……たぶん」「やっぱり、盗まれたんだ……」는 끝을 낮게 흐리고, 「見つかりました！」는 높게 터뜨린다.
- **질문 억양**: 경찰관 「君の自転車？」「いつ？」는 끝을 올리고, 「〜ですね」 확인은 평평하게.

## 어휘·표현

| 표현 | 읽기 | 뜻·쓰임 |

| 駐輪場 | ちゅうりんじょう | 자전거 주차장 |
| 鍵をかける | かぎをかける | 자물쇠를 잠그다 |
| ツーロック | つーろっく | 자물쇠 두 개 사용 (방범 캠페인 용어) |
| 盗まれる | ぬすまれる | 도둑맞다 (「盗む」의 수동) |
| 盗難 | とうなん | 도난 |
| 交番 | こうばん | 파출소 |
| おまわりさん | おまわりさん | 순경 아저씨 (친근한 말) |
| 届けを出す | とどけをだす | 신고서를 내다 |
| 被害届 | ひがいとどけ | 피해 신고서 |
| 防犯登録 | ぼうはんとうろく | 자전거 방범 등록 (구입 시 의무) |
| 特徴 | とくちょう | 특징 |
| 乗り捨てる | のりすてる | 타고 가서 버리다 |
| 放置自転車 | ほうちじてんしゃ | 방치 자전거 |
| 保管所 | ほかんじょ | (구의) 방치 자전거 보관소 |
| 準備中 | じゅんびちゅう | 준비 중 (가게 문에 거는 팻말) |
| ご迷惑をおかけして | ごめいわくをおかけして | 폐를 끼쳐서 (정중한 사과) |
| 正直に | しょうじきに | 솔직하게 |
| 〜てある | 〜てある | (누군가 해 둔) 상태: 「シールが貼ってありました」 |

### 말투 포인트
- 리쿠는 어른에게 「〜です／〜ました」, 엄마에게는 「〜の」「〜ちゃった」. 어린이의 경어는 단순하고 짧게.
- 경찰관은 아이에게 「〜かな」「〜だね」로 부드럽게, 어른에게는 「お持ちですか」「いらっしゃったら」 존경어.
- 이사오는 자신을 낮춰 「同じビルに住んでいる者です」 — 「者(もの)」는 자기소개용 겸양.
- 〜ている(결과 상태): 「かごがついています」「シールを貼っています」「乗り捨てられている」.

## 한글 해석

[장면: 찻집 가돗코 / 토요일 아침 9시]

리쿠: 이사오 아저씨! 이사오 아저씨!
이사오: 어, 리쿠. 좋은 아침. 왜 그래, 그렇게 뛰어와서.
리쿠: 제 자전거가 없어요!
이사오: 자전거? 어디 뒀는데?
리쿠: 건물 앞 자전거 주차장이요. 늘 두는 자리.
이사오: 언제 뒀어?
리쿠: 어제 저녁이요. 5시쯤 축구 끝나고 와서 세워 뒀어요.
이사오: 자물쇠는? 제대로 잠갔어?
리쿠: 잠갔어요! ……아마도.
이사오: 아마도, 라.
리쿠: 아니, 잠갔어요. 진짜 잠갔어요. 찰칵 소리가 났거든요.
이사오: 알았어, 알았어. 진정해. 엄마는?
리쿠: 벌써 일하러 가셨어요. 오늘은 아침 7시부터예요.
이사오: 그렇구나. 란 씨는 토요일에도 일찍 나가는구나.
리쿠: 어떡하지……. 그거 새 자전거예요. 지난달에 할머니가 사 주셨어요.
이사오: 파란 거지? 멋있다고 자랑했었잖아.
리쿠: 네……. 오늘 10시부터 축구 연습이 있는데.
이사오: 연습은 쉬어. 우선 같이 찾자.
이사오: "준비 중" 팻말을 걸고, 자. 좋아, 가자.

[장면: 건물 앞 자전거 주차장 / 아침 9시 10분]

이사오: 여기야?
리쿠: 네. 여기 세워 뒀어요. 이 기둥 옆이요.
이사오: 다른 자전거는 있네. 다이치 것도, 마리 것도.
리쿠: 제 것만 없어요.
이사오: 뭐 떨어진 거 없나? 자물쇠라든가 부품이라든가.
리쿠: 음……. 아무것도 없어요.
이사오: 주변도 좀 둘러보자. 누가 타고 가서 어딘가에 세워 뒀을지도 몰라.
리쿠: 건물 뒤쪽도 볼게요!
이사오: 그래. 난 모퉁이 건너편을 볼게.
리쿠: ……없어요. 뒤쪽엔 낡은 자전거 한 대만 있어요.
이사오: 여기도 없어. 편의점 앞에도 없었고.
리쿠: 역시 도둑맞은 거야…….
이사오: 울지 마, 리쿠. 파출소에 신고하자.
리쿠: 파출소요? 경찰이요?
이사오: 그래. 자전거가 없어지면 파출소에 가는 거야. 찾는 경우도 많아.
리쿠: 근데 뭐라고 말하면 돼요?
이사오: 순경 아저씨가 물어봐 주니까 괜찮아. 아, 엄마한테 전화해 둬.
리쿠: 네. ……여보세요, 엄마? 나 리쿠.
란: 리쿠? 무슨 일이야? 엄마 지금 일하는 중이야.
리쿠: 미안. 자전거가 없어져 버렸어.
란: 뭐? 그 새 거?
리쿠: 응. 지금 이사오 아저씨랑 파출소 가.
란: 이사오 씨가 같이 계셔? 잠깐 바꿔 줘.
이사오: 여보세요, 란 씨. 가도노예요.
란: 이사오 씨, 죄송해요, 폐를 끼쳐서.
이사오: 괜찮아요. 파출소 다녀올게요. 방범 등록 번호 아세요?
란: 음…… 집 서랍에 카드가 있어요. 점심때 쉬는 시간이 있으니까 파출소로 가져갈게요.
이사오: 알겠어요. 그럼 먼저 얘기해 둘게요.

[장면: 오시아게 파출소 / 아침 9시 40분]

경찰관: 네, 무슨 일이세요?
이사오: 실례합니다. 이 아이 자전거가 없어져서요.
경찰관: 도난이군요. 네 자전거니?
리쿠: 네. 제 거예요.
경찰관: 이름 알려 줄래?
리쿠: 나카무라 리쿠예요. 열 살이에요. 초등학교 5학년이에요.
경찰관: 나카무라 리쿠 군이구나. 이쪽 분은 아버지세요?
이사오: 아니요, 같은 건물에 사는 사람입니다. 1층에서 찻집을 하고 있어요.
경찰관: 그러시군요. 보호자분은요?
이사오: 엄마가 일하는 중이라 점심때 여기로 오신대요.
경찰관: 알겠습니다. 그럼 리쿠 군, 몇 가지 물어볼게.
리쿠: 네.
경찰관: 자전거를 어디에 세웠어요?
리쿠: 집 건물 앞 자전거 주차장이요. 교지마 모퉁이 건물이에요.
경찰관: 언제 세웠어요?
리쿠: 어제 저녁 5시쯤이요.
경찰관: 없어진 걸 안 건 언제야?
리쿠: 오늘 아침 9시 조금 전이요.
경찰관: 그럼 어제 5시부터 오늘 9시 사이구나.
리쿠: 네.
경찰관: 자물쇠는 잠갔었어요?
