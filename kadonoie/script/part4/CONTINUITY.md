# 第4部 冬 연속성 메모 (난이도 N2~N1, 2026년 12월~2027년 2월)

## 3부에서 넘어온 상태 (2026년 11월 28일 기준)
- 角野ビル: 10/1부터 ミナモステイ不動産 소유(2.5억, 대출). 11월 업자용 사이트에 3.2억 재매각 등록(住居5戸 중 1 공실, 店舗2, 賃借人あり, 建て替え計画あり). 매수자는 해외 펀드일 수도. 武田(信金): 미나모 자금 사정 악화 소문.
- 주민 원칙: 미나모에게 혼자 답하지 않기. 변호사 西村: 정당 사유 근거는 미나모 계열 업체의 Is値 0.28 簡易診断(방 내부 미조사) → 세컨드 오피니언 필요. 구 월세 지불, 거부 시 供託.
- ★54화 이사오 결단: 퇴거료(구로다 최종 1000만) 거부, 가게 계속, "このビルを、買い戻すことにした"(방법 미정). 武田 「角野さんがお一人だとは思っていません」.
- 마리: 12/26 퇴사. 그 전에 상사 桐生(부동산 재생 전문)에게 주민 매입 방법을 물어보기로.
- 다이치(早瀬): 정기차가 12월 중순 만료 통지 → 안 나가기로. 西村가 하루 씨와의 계약(4년 전) 사전 설명 서면 유무 확인 중(미비 시 보통 차가). クイックデリ 계약 재협상(프리랜서법), 인보이스 과제. 케이(배달원)가 자전거 수리 배우는 중.
- 란(40): 리쿠 입시 2/3(도립 중고일관교 適性検査)까지는 무조건 거주. 「みんなで」에 대한 고백 → 56화에서 合同会社 제안. 52화 외국 국적 부모 때문에 입주 거부 경험.
- 리쿠(11, 6학년): 작문 「わたしの町」(「ぼくの家は、もうすぐ、なくなるかもしれません」), 방재 지도(이 건물 = "町の舟"). 「そういう大家さんがいない国にしたい」.
- 시게 씨(83): 10/21 카테터 어블레이션, 10/23 퇴원. 친구 金子勇의 노기스. 「このビルの柱」.
- 다쿠미(27): 9/30 실업, 실업급여 90일(12월 말 종료 예정), 職業訓練 검토. 미사키(간호사)와 교제 중. 셰어하우스(曳舟) 겐지·유나·렌.
- 옥상 누수: 미나모 미수리, 블루시트(다이치 점검). 4층 빈방 열쇠는 미나모 보유.
- 소품: 하루 씨의 작은 熊手(계산대 위, 54화), 두 동강 난 선대 간판(나란히 둠), 1978년 준공 사진 뒷면 「このビルは、みんなの家。売らない。松井ハル」.
- 하루 씨: 1930년경생, 1958년 가노가와 태풍 때 2층 목조집에 이웃 20명 피난 → 1978년 4층 빌딩 "町の舟". 선대에게 무이자 대출.

## 화별 기록
### 55 忘年会と川柳 (12/5 토)
- 매년 12월 첫 토요일 かどっこ 망년회. 가오루 기획 「かどっこ川柳大会」, 상품 「来年、コーヒー一か月無料券」. 마리(송별회 준비)·란·리쿠(모의시험) 불참/지각.
- 작품: 이사오 「米の値で　コーヒー代が　また上がる」(쌀값 작년 두 배 가까이, 커피 50엔 인상) / 다이치 「青切符　ライト修理が　急に増え」(4월 자전거 青切符, 무등화 범칙금 → 4월 매출 역대 최고), 「インボイス　番号だけが　増えていく」 / 가오루 「時給上げ　シフトを減らす　壁の前」(소득세 벽 103→160만, 사회보험 130만 벽 → 11·12월 근무 감축), 「お客様　神様じゃない　人間だ」(카스하라 조례) / 다쿠미 「AIに　仕事とられて　ハローワーク」(字余り, 「人生も、字余り」), 「路地裏に　スーツケースの　音ひびく」(유나가 동네 소리 녹음 희망) / 시게 「冷房の　効いた店まで　避難する」, ★「売らないと　書いた裏書き　まだ生きる」 → 우승.
- 다쿠미: 실업급여 12월 종료, 2027년 1월부터 직업훈련(데이터 분석, 반년), 職業訓練受講給付金 조건 확인 중.
- 이사오 「一か月と言わず、来年も、再来年も」.
- 훅: 란 LINE 「明日、みんなに話したいことがあります」「会社の作り方、調べました」 → 56화(12/6 일).

### 56 ランの思いつき (12/6 일)
- 란이 3주간 조사(손글씨 노트 2권, 도서관·구 창업 상담 창구 2회). 계기: 직장 선배의 니가타 산골 마을 — 유일한 슈퍼 폐점 → 주민 합동회사로 매입·운영(5년째, 선배 어머니 5만 엔 출자 「私の店」, 첫해엔 매일 밤 말다툼).
- ★제안: 주민 合同会社가 건물 매입. 설립비 약 10만(주식회사 약 20만). 출자자=소유자=경영자, 출자자를 「社員」이라 부름(시게 「八十三で、就職かい」). 定款으로 출자액 무관 1인 1표 가능 → 이사오 「ハルさんが言ってたことと、同じだ」.
- 단점·위험: 有限責任이지만 은행 융자 시 대표의 連帯保証 요구 많음(란이 숨기지 않음). 큰 빚, 수리·쓰레기도 자기 책임, 돈 문제로 사이가 나빠질 수 있음.
- 다이치 계산: 현재 월세 합계 월 60만 남짓(4층 공실) vs 2.5억 30년 대출 시 월 약 90만 + 내진·지붕 별도 → 크게 부족. 란 「数字は、まだ全然」「こういう道もある」.
- 논점: 사원 범위(주민·종사자=사원, 오카와·단골·다쿠미·가오루 등 외부=「応援する人」 구분 가능), 탈퇴 시 출자금 처리 미리 정하기(다이치 「結婚みたい」, 시게 「結婚より、よっぽど正直」).
- 마리가 기리유에게 확인: 법인 매입이 융자·세금·상속 정리에 유리한 경우 많음, 유럽엔 주민 회사 매입 사례 꽤 있음. 자기 자금 최소 20%(3억이면 6000만). 3.2억은 희망가, 미나모 자금 사정 → 협상 여지. 기리유가 마리 퇴사 전 주민을 만나고 싶어 함, 란 노트 전달.
- 시게 씨 10만 엔 출자 선언. 회사 이름은 「みんなで決めよう」 → 57화.
