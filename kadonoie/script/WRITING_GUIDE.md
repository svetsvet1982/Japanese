# 《角の家》 대본 집필 가이드 (모든 화 공통)

설정: `kadonoie/角の家_일본어_연속대화문_기획서.xlsx` (화별 개요·등장인물·문체 원칙), 각 부 `CONTINUITY.md`
견본: `script/part1/ep01.md` — 형식·밀도·톤을 맞출 것.

## 파일
- `kadonoie/script/partN/epXX.md` (XX = 전체 화 번호 01~90, 두 자리)
- 각 부 폴더의 `CONTINUITY.md`를 화마다 갱신 (새 인물, 확정 사실, 복선, 다음 화 훅)

## 형식
1. 제목: `# 《角の家》 第N部 X 第XX話 「제목」（한국어 제목）`
2. 정보 표: 시기 / 난이도 / 등장인물 / 턴 수(120) / 학습 포인트
3. `## 본문` — 장면 표시 `【場面：장소／시간】`, 대사 `話者：台詞` (턴 번호 없음, 한 줄 한 턴, 지문 없음, 정확히 120턴)
4. `## 낭독 포인트` — 5~7개 불릿 (장음·촉음·ん, 무성화, 악센트, 축약, 억양, 下町 발음 등 그 화에 실제 나오는 예)
5. `## 어휘·표현` — 표 15~20개 (표현 | 읽기 | 뜻·쓰임). 속어는 `[속어]` 태그와 사용 가능/불가 상황
6. `## 한글 해석` — 본문과 같은 순서·같은 줄 수로 `화자: 번역` (장면 표시는 `[장면: …]`)

## 화자 표기 (본문 → 해석)
イサオ→이사오, マリ→마리, ダイチ→다이치, ラン→란, シゲ→시게, タクミ→다쿠미, オオカワ→오카와, リク→리쿠,
カオル→가오루, ミサキ→미사키, ミン→민, ホア→호아, アヤ→아야, ケンタ→겐타, 田村→다무라, 黒田→구로다,
武田→다케다, 西村→니시무라, 松井→마쓰이. 단역은 역할명(警官→경찰관, 客A→손님A 등).

## 원칙
- 한 화 화자 2~4명, 카페 장면 최대 5명. 화마다 주인공이 바뀜.
- 난이도: 1부 N4~N3 / 2·3부 N3~N2 / 4·5부 N2~N1. 1부는 어려운 한자에 괄호 읽기 병기.
- 한 호흡 30자 안팎. 문말 억양·담화표지·축약을 자연스럽게.
- 현안 수치·시행일은 단정하지 않고 화자의 인식으로(「〜らしいよ」).
- 실존 인물·기업·정당명 금지. 실제 지명·행사·제도는 사용.

## 검증
```bash
python3 kadonoie/tools/check_episode.py kadonoie/script/partN/epXX.md
```
본문 120턴, 해석 120턴, 화자 대응 일치여야 OK.
