# 第5部 『水が来た日』（물이 온 날）

## 개요
| 항목 | 내용 |
|---|---|
| 기간 | 2028년 7월 ~ 11월 |
| 무대 | 江東区 전역, 학교 체육관 피난소, 区 재해대책본부, 都庁, 피해 상점가, 千葉·埼玉의 광역 피난처 |
| 모티브 | 대형 태풍+고조+내수 범람(가공 재해 「令和10年台風第8号」), 江東5区 広域避難 판단과 혼란, 避難所 TKB(화장실·주방·침대)와 スフィア基準, 災害関連死, 能登半島地震의 교훈, 罹災証明·被災者生活再建支援法, 재해 데마(외국인 절도 데마), 防災庁, 都区財政調整, 재해 자원봉사 센터, 정치인의 실언과 사퇴 |
| 테마 | 「ここにいてはダメです」 ― 그 말을 누가, 언제, 어떻게 말할 것인가 |
| 대립축 | 늦은 판단의 관료주의, 「自己責任」 실언의 衆院議員 久世 隆, 재해 데마 |
| 주인공의 변화 | 区議 → 현장 리더로 전국 뉴스에 → 국가 정치의 공백을 본다 → 국정에 나설 결심 |

| 게스트 | 区 방재과장 **高橋 修平**(48), 都 방재 담당 부장 **安藤 京子**(55), 能登 출신 재해 NPO 대표 **能村 隆**(45), 防災庁 정무관(가공) |
