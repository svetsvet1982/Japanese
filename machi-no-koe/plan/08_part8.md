# 第8部 『くにの声』（나라의 목소리）

## 개요
| 항목 | 내용 |
|---|---|
| 기간 | 2030년 1월 ~ 6월 |
| 무대 | 신당 「くらしの声」 본부(神田의 임대 빌딩), TV 스튜디오, 전국 유세지(能登·福島·北海道·大阪·沖縄·鹿児島), 江東 선거구, 개표 센터 |
| 모티브 | 衆院 해산·총선거, 인구 감소와 지방 소멸, 能登 부흥, 福島, 北海道 철도 폐선·외국자본의 토지·수원지 매수, 大阪(IR·광역행정), 沖縄 기지 문제·관광 의존, 「金利のある世界」(국채 이자·일본은행 금리 인상·변동금리 주택대출), 외국인 노동자와 공생 정책, AI와 고용, 「日本人ファースト」형 포퓰리즘과의 정면 토론, 少数与党·連立の組み替え |
| 테마 | 「まちの声」を「くにの声」に ― 큰 이야기를 작은 이야기의 언어로 말할 수 있는가 |
| 대립축 | 再生党 대표 千石 翔, 협화당 총리 松平 修一, 협화당 원로 鬼塚 剛三과 「関東湾龍会」, 신당 내부의 노선 대립 |
| 주인공의 변화 | 1기 의원 → 신당 政務調査会長(정책 책임자) → 전국적 정치인 → 선거 후 신당 대표로 선출 → (9부) 총리 후보 |
| 일상 : 시사 | 3 : 7 |
| 게스트 | 能登의 어부 **浜中 勇**(70), 福島 귀환 주민 **佐藤 ミツ**(81), 北海道 낙농가 **本間 拓也**(39), 大阪 상인 **吉村 のり子**(66), 沖縄 청년 **比嘉 大翔**(24), 鹿児島 해산물 가공회사 **東郷 健**(52) |
