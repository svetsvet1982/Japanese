# 第1部 『まちの声』（동네의 목소리）

## 개요
| 항목 | 내용 |
|---|---|
| 기간 | 2026년 10월 ~ 12월 |
| 무대 | 江東区 北砂・砂町銀座商店街, 南砂 타워맨션, 区役所 |
| 모티브 | 물가 상승·쌀값, 고령 단신 세대 고독사, 孤独・孤立対策推進法, 民生委員 인력난, 町会 가입률 저하, 외국인 주민과 쓰레기 배출, 子ども食堂, 江東5区 수해 광역피난, 闇バイト 강도 불안, 銭湯 폐업, 空き家·相続登記 의무화, 재개발 설명회 |
| 테마 | 「誰かがやってくれる」의 「誰か」는 이제 남아 있지 않다 |
| 대립축 | 町会(下町·고령) vs 타워맨션(신주민·맞벌이), 「前例がない」는 区役所, 재개발 디벨로퍼 「湾岸みらい開発」 専務 **栗林 達彦**(55) |
| 주인공의 변화 | 평범한 회사원 → 町会 청년부장 → 동네 사람들의 「대변인」 → 「立候補」라는 말을 처음 듣는다 |
| 일상 : 시사 | 7 : 3 |
| 게스트 | 吉岡 正一(84), 民生委員 森下 照代(72), 銭湯 「砂町湯」 주인 **小松 義男**(76), 空き家 주인의 조카 **西村 健二**(49) |
