# 第1話 「予報円」 (2028-07-10 ~ 07-12)

## 확정 사실

- 7/11 防災課 **高橋 修平(防災課長, 区役所 26년)**: 台風8号 오키나와 남쪽, **920hPa**, 금요일 밤 예보원 **직경 500km**(東京湾·房総·伊豆 포함), 東京湾 직격 확률 현시점 3~4할. 고조 3m 이상 가능. **72시간 전 = 7/12(수) 8시 5구 온라인 회의**(5구장·気象庁·国交省·東京都).
- **「空振り」 딜레마**: 共同検討開始 발표 = 계획운휴·휴교·휴업 판단 촉발. 빗나가면 수천억 엔 손실·「オオカミ少年」. **区長 鶴岡 「高橋くん、空振りしたら、誰が、責任を取るんだ」**(내년 区長選, 民生党 후보 예정). 高橋는 전날 밤 3번 「出すべき」 → 3번 「もう少し様子を見よう」. 5구 어느 区長도 실제 광역 피난을 낸 전례 없음. 高橋 「決める人を動かせるのは、外から押す人です」.
- 町会: 寺田가 반장 전원에게 전화 — 반은 「どこに逃げりゃいい」, 반은 「二階があるから大丈夫」(寺田 자신도). **伊勢湾台風(1959) 때 11세, 라디오, 아버지 「次は東京だ」** → 70년간 안 옴. 森下: 담당 독거노인 **110명 중 「逃げない」 80명**(행선지 모름·다리·고양이·집 비우기 싫음). **吉村 「朝倉さんが逃げろって言うなら、逃げるわ」**.
- ひまわり荘: 외국인 노동자 「休んだらクビ」 걱정. 王 「『広域避難』、何の意味？」, ビカス 「高潮」 네팔어 단어 없음 → 「바다의 물」로 설명. **ラン: 「たかしお = うみの　みずが　たかく　なって、まちに　くる」** — ベトナム語+やさしい日本語, 王 中国語, ビカス ネパール語로 LINE 배포. 「どこに逃げればいいですか。千葉？埼玉？」 → 미정.
- 控室(밤): 石井 — 北砂 최대 침수 5~10m. 篠原 — タワー 고층 주민 다수 「垂直避難」, 그러나 1층 전기설비 침수 시 엘리베이터·수도 정지, 32층 2주 생활. 中村 「低層階の人だけでも先に」. 石井 vs 篠原: 공振り 경제 손실(병원 수술 등) vs 생명. 大野: 「決めた人を、空振りのときに、責めない、と、誰かが約束しないといけない」 → **議会가 먼저 약속**.
- **7/12 7시 区長室 앞: 회파 대표 6명 유지 申し入れ**(陽介·石井·大野·小西(竹中 반대 무릅씀)·本間(区長選 재료 포기)·岸本·森川) — **「台風第八号への対応に関する申し入れ」 ①5구 회의에서 공동 검토 주저 없이 개시 ②빗나가도 議会는 적절한 판단으로 평가하고 区長 책임을 묻지 않는다**. 陽介 「空振りなら、私たちが、一緒に、謝ります。間に合わなかったら、謝る相手が、いなくなります」.

# 第2話 「逃げるか、残るか」 (2028-07-12 ~ 07-14 朝)

## 확정 사실
- ひなた 배낭: 3일분 옷·칫솔·수건·물통 + 가장 소중한 것 = **곰 인형 「こむぎ」**, + 여름방학 드릴.

- 文子: **亡夫의 히노키 두부 틀(40년, 모서리가 닳아 둥글어짐)**, 亡夫가 작업장에서 새벽 4시에 쓰러졌고 文子가 발견 → 「お父さんを、もう一回、一人にするみたい」. 陽介 「ひなたのそばにいられるのは、母さんだけ」 → 「ずるいわね」 → **柏행 수락**. 亡父는 조합 스트라이크 때 「俺が、最後まで、残る」.
- **7/13(목) 8시 48h 「自主的広域避難」 호소**(5구 区長 회견). **しず子 = 大地 밴으로 船橋 여동생 집**(2년 전 개별 피난 계획대로). **寺田 거부**(「町会の年寄りが全員逃げたのを確かめるまで」, 狩野川·伊勢湾 때도 안 피함) → 森下 「正常性バイアス」 → 寺田 「俺が残ってたら『町会長が残ってるんだから大丈夫だ』って残るやつが出る」 → **「全員に『逃げろ』と言って回る。言い終わったら、逃げる」**(江戸っ子に二言はねえ).
- **小松(北砂三丁目 3층, 아이 3세·1세)**: 「三階だから大丈夫」 → 2주 단전·단수·7월 무냉방·분유·기저귀 → **아내 친정 所沢로 오늘 밤**.
- **吉村: 区 福祉차량, 7/14 9시, 埼玉 시설**(남편 사진·약·옷). 「約束は、守るわ」. **吉岡 거부**: 「キミさんの家だぞ。五十年」, **시설은 「知らねえ場所で知らねえ人間に囲まれて」 싫다, 「二階で寝てる」, 「水が来たら、二階の窓から、手を振る。それで、勘弁しろ」**(→ 5화 복선).
- **陽介 = 北砂에 남음**: 北砂小 신교사 **3층 = 区 「緊急避難場所」** 운영 지원. 美咲: 1부 「あなたも来るんでしょ」 회수 — 「あのとき、もう決めてたんでしょう」. 「仕事だから残るんじゃない。逃げない人を置いていけないから。それは陽介の性格」「最後の一人を探しに行って、自分が最後の一人になっちゃう人」. 능登 응원 선배 「助けに行った人が、一番、壊れて、帰ってくる」. **세 가지 약속: ①위험하면 즉시 피함 — 「最後から、二番目」 ②매일 1회 LINE 「生きてる」 ③ひなた 마중은 陽介가**. 美咲도 매일 「生きてる」, 「私だって、怖いよ。忘れないで。私たち、二人とも、残るんだから」.
- **7/14(금) 7시 출발**: 大地 밴(히노키 틀 수건 3겹), ひなた 「みんな、ばらばら」, **ゆびきり(마중은 パパ)**, **ひなた가 「こむぎ」를 陽介에게 빌려줌 — 「むかえにくるとき、かえしてね」**. 文子가 **가게 열쇠**를 陽介에게(「帰ってきて、また、開ける」), 文子도 「最後から、二番目よ」. **大地: 真奈美·奏는 어제 真奈美 친정으로, 자신은 柏→船橋(しず子) 후 귀환, 정육점 냉장고 지킴** — 「おまえが二番目なら、俺が三番目だ」.
- 9시 寺田: 반장 3명 연락 두절 → 陽介와 함께 순회.

# 第4話 「体育館の夜」 (2028-07-15 早朝 ~ 07-16 未明)

## 확정 사실
- 7/15 6시~ 소방 보트가 北砂小 현관으로 구조자 수송(北砂·南砂 2층 잔류자 수천 명, 北砂小 = 가장 가까운 고층 건물). **颯太 + 할머니 森 キヨ**(南砂 단지 5층, 엘리베이터 정지·무릎, 소방 2명이 업어 내림), 颯太 어머니는 介護 파트 병원에 숙박 근무. 颯太 = 사회복지학부 1학년, 자원봉사.
- 9시 **小田(区 防災課, 운영은 연수뿐)**: 区 매뉴얼 = 「避難者自身による自主運営」 → **避難所運営委員会**: 총무 **寺田**, 식료 **篠原**, 물자 **颯太**, 구호 **田中(전직 간호사, 육아휴직 중)**, 다언어 **ラン**(+王 중국어·ビカス 네팔어, **ビカス는 네팔 동료 15명과 보트로 도착**), 요배려자 지원 + 전체 조정·区 본부 연락 **陽介**. **村井 교감**: 가정실·보건실·도서실 개방.
- 11시 **화장실 전부 막힘**(단수인데 물 내림). 휴대용 화장실 200명 3일분, **맨홀 화장실 5기는 침수된 교정**. 田中: 화장실 → 음수 회피 → 탈수 → 혈전·뇌경색 → 「災害関連死」(能登·熊本). 篠原: **TKB(トイレ·キッチン·ベッド)** 셋 다 없음. 본부에 휴대용 화장실 1,000명분 요청 → **옥상 수영장 물로 양동이 릴레이**(颯太 지휘).
