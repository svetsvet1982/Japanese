# 第2話 「推薦状」 (2028-12-21 ~ 2029-01-10)

## 확정 사실
- **선거 사무소 = 다시 砂町銀座 옛 이불가게**. 진용: 黒須(참모), **篠原(정책 담당, 주 3일)**, **佐野(대학 4년, SNS·영상)**, 長尾(다음 주부터 ウグイス嬢).
- 篠原 표: 民生党 vs みらい — 원전·안보·消費税·헌법 4개에서 정반대. 黒須 「真ん中じゃなく、朝倉さんの言葉」.
- **12/21 野口(民生党)**: 公認 거절 확인 → 推薦 조건 ①原発ゼロ ②安保法制 違憲部分 廃止 ③消費税 한시 5%. 陽介: 태풍 정전·美咲의 수동 인공호흡 → 「止まらない電気」, 「原発ゼロ」 대신 **「新しい原発は作らない・再エネと蓄電を最大限・既存原発は安全と地元同意を前提に段階的に依存度を下げる」(날짜 없음)**. 篠原: **消費税 5% 인하 = 연 약 12조 엔 세수 감소, 법인세로 메우려면 거의 2배** → 野口 「数字の厳しい方を連れてきましたね」.
- **12/22 橘(みらい)**: 「段階的に減らす」는 みらい엔 반대 방향(재가동·전기요금·데이터센터), 차세대 소형원전 연구 의견도 있음. **安保法制 廃止는 절대 불가**(대만해협·한반도). 방위비는 필요분, 재원 명시·국채 금지. 陽介: **안보는 「まだ自分の言葉になっていない」 — 区議会 국민보호 질문까지만 말할 수 있다, 「わからないことをわからないと」** → 橘 「弱い。でも正直」. **黒須: 安保·憲法은 협정에서 빼고 후보 본인 판단, 토론회에서 자기 말로**.
- **2029/1/1**: 文子는 매년 원단 亡夫 불단에 두부 1丁. 寺田: 町会 신년회 화제 「民生党か、みらいか」 — 협화당 지지 노인 「赤くなった」, 조합 OB 「みらいは金持ちの党」 → 陽介 「両方から推薦をもらって、どっちの色にも染まらない。豆腐は白いので」 → 寺田 **「白いままでいろよ。北砂の年寄りは白い豆腐が好きなんだ」**. 美咲: 자기 이야기 사용 허락, 원전은 「わからない」, **「陽介は『わからない人』の代わりにちゃんと考える人でいて」**.
- **1/10 新宿 호텔 3자 협의 → 「政策協定書」 5항목 합의·서명**: ①政治とカネ(企業·団体献金 금지, 政策活動費 폐지, 수지 실시간 공개) ②防災と被災者の再建(防災庁 3제안 법제화, **被災者生活再建支援法 개정으로 「半壊」도 지원 대상** — 1회 대재해당 추가 수백억, 국가·도도부현 기금 적립으로 대응 가능) ③働く人の手取りとケア(최저임금 단계 인상, 介護·保育·学童 처우 개선, 社会保険料 「見直し」) ④子どもと若者(不登校 다양한 배움, ヤングケアラー, 学童 대기 해소) ⑤エネルギー(신증설 없음·재에너지·축전 최대·기존 원전 안전·지역 동의 전제 단계적 의존도 저감·재해 시 멈추지 않는 전력). **安保·憲法 = 본인 판단**. 陽介 「党の約束じゃない。一人の候補者の約束」, **「党と違う安保の話をしたら、推薦を取り消してください」**. 野口 추가 조건: **당선 후 양당과 정기 정책 협의**. 野口 「礼は、勝ってから」 橘 「同じく」. 佐野가 3인 사진.
- **野口: 무소속 후보와의 협정은 두 번째 — 첫 번째는 20년 전 藤代 静香의 마지막 선거(野口는 당시 젊은 비서로 포스터 부착)**. **黒須도 그 선거가 선거 일의 시작, 野口와 「相棒」** → 이후 당/무소속으로 갈림. 新宿 뒷골목 라멘집(20년 만). **橘: 오사카 町工場 출신, 아버지 선반공(陽介 아버지와 같음), 당시 IT 회사원**. 野口 「党の看板がなけりゃ、こんなもんだ」 → 黒須 「だから、朝倉さんが、看板のない候補」.
- 野口 경고: 雄大는 성실, 뒤의 鬼塚는 아님. 橘: 千石가 「野合」「野党の操り人形」이라 할 것 → 「言い返すのは、選挙区を歩いた足の数」.

# 第3話 「選挙区は広い」 (2029-01-13 ~ 01-27)

- **石井의 豊洲 타워 공용 라운지**(みらい 区議로서 응원, 「豊洲の人を紹介できるのは私だけ」). 豊洲 15년간 인구 2배, 30·40대 맞벌이, 江東区 출신 1할 미만, 町会 없고 관리조합만. **篠原 데이터: 선거구 유권자 약 43만, 湾岸 신축 맨션 주민 35%, 下町(北砂·亀戸·大島 등) 40%, 나머지 중간 주택지. 湾岸은 국정선거 투표율이 높음(전 衆院選 豊洲 투표소 6할 초과), 무당파 7할(전회는 みらい·協和党로 분산)**. 黒須: 「北砂の人」이라는 인식이 약점(「自分たちとは関係ない下町の被災地の人」). 石井도 区議選 때 「豊洲のタワマンの女」라 불림 — 「逆もある」.

- **夢の島**: 옛 쓰레기 매립지(고도성장기 「ゴミ戦争」), **第五福竜丸 전시관(75년 전 비키니 수폭 실험 피폭선, 폐선 후 시민 보존 운동 — 「捨てられたものを記憶として残す」)**. 黒須: 区議選은 「砂町」 표로 이김(43만 중 1할) → **「区議選の十倍の顔を持て」 = 「言うことを変えるのではなく、どこから話し始めるかを変える」**, 정책은 하나 「名前のある一人一人を、ひとりにしない」. 篠原: **陽介는 이미 区議会 建設委員会(2027.6.22)에서 湾岸 타워 사전협의·학교 수용 문제를 질문했음(湊斗의 南砂みどり小)** → 「十の顔を持っているが北砂の顔しか見せていなかった」. 佐野: **의사록 지역별 영상 「豊洲編」「亀戸編」「大島編」**(투표 호소 없이).
- **1/27 豊洲 라운지 2차 다과회(15명)**: **高木(有明 초등 2년 아들, 가설 프리패브 교실, 맨션 理事)**. 陽介: 建設委員会 의사록 제시(「計画の変更を求める権限はない」「配慮のお願い」) → 국가에서 도시계획법과 학교 정비 연결, 개발 사업자의 학교 비용 일부 부담. **湊斗(현재 3학년, 아직 가설 교실·교정 교대 주 2일)** 이야기, 篠原 직접 확인. 消費税는 내리지 않지만 社会保険料 구조·맞벌이가 손해 보지 않는 세·보험, 「払った税金が子どもに返ってくる」. 高木 「豊洲を優先しますか」 → **「優先はしません。豊洲も北砂も。どちらも『後回しにしない』」(3부 師長 遠山의 말)** → 「ずるい答え。でも『豊洲を優先』と言われたら信じなかった」 → **의사록 사본을 관리조합 300세대에 「学校の話」로 회람**. ソン 남편에게 전하겠다.

# 第4話 「透明な財布」 (2029-01-29 ~ 02-11)
