# 第1話 「区議を辞める」 (2028-12-11 ~ 12-20)

## 확정 사실
- 控室 짐 싸기: 골판지 5상자(의사록·원고·주민 편지, 「夏休みの朝の地図」, 颯의 「助けて」 메모, 吉川 출석 인정 기준 첫 안). 찢어진 소파는 「三階の奥の歴史」로 남김. **당선 밤 ひなた 메모 「ようすけ　ひゃくじゅうに」는 의원회관까지 가져가기로**.
- **片岡**: 회기 중 사직은 본회의 허가(지방자치법), 정례회 최종일 12/20 「議員辞職許可の件」, 퇴임 인사 약 3분, 배지는 사직일 반납(区 비품). **결원 1 → 補欠選挙 없음(정수 6분의 1 = 7명 초과 시만), 北砂 의석 2년 반 공석**. 「通告書はいつも一番薄かった。議事録はいつも一番厚かった」.
- 12/14 **竹中**: 「区議会を踏み台に」「北砂の声が届かなくなる」「死んだ父親を選挙の道具に」 → **堀之内가 제지**(温泉 영수증 공개 덕에 반환으로 끝났음을 상기). 堀之内: 「北砂の席が空く、約束を破る — その二つは背負っていけ。言い訳をしないで」, 「父親の亡霊」은 竹中의 질투 — **竹中의 아버지도 区議(3선 후 낙선), 竹中는 그 지반을 계승**. 「世襲は悪くない。継いだものを自分の言葉に変えられるかどうか」.
- 12/15 **高橋**: 区 공식 기록지 「台風第八号　江東区の記録」 원고(2029년 3월 출판, 区議会 申し入れ 1쪽). **防災庁 검증위 최종 보고 골자에 3제안 전부 반영** — ①72h 광역피난 판단 공振り 시 판단자 책임 불문을 国 지침에 ②발재 첫날 골판지 침대 등 国·사업자 사전 협정 ③요지원자 명부 외 주민에 대한 이웃 声かけ를 地域防災計画에. **각주: 「令和十年十月五日、参考人・朝倉陽介江東区議会議員の意見陳述による。北砂小学校避難所において井上茂氏(七十九歳)が災害関連死と認定」(若宮가 직접 기입)**. 高橋(区役所 27년) 「『国の制度でございますので』と言わなくてすむように」.
- 12/18 인계: **陽介 질문 31항목 — 「やる」 12·「検討」 14·「わからない」 5**. 石井·大野가 추적(국민보호 연계 검토팀 보고 2029년 3월, 学童 8시 지속, 헬퍼 이동 지원 → 당초예산 항구화, 프리스쿨 보조 → 내년도 요망, **ハラスメント防止条例 2029년 3월 제출 — 공동제안 森川·岸本·小西**). 새 회파명 **「江東ひとりにしない会」**(石井 고집). 답변 해독표에 **「善処します」 = 「何もしない、とは言わない」**(국회용) 추가. 「軽い言葉の中で、重い言葉を一つ言えるかどうか」.
- **12/20 第四回定例会 최종일**: 「議員辞職許可の件」 이의 없음 → 허가. 퇴임 인사(3·358표·43번 의석·첫 질문 실패·답변 해독·8월 早朝 전 회파 申し入れ·「言い訳は、いたしません」·「区長が『国の制度が変わりましたので、実施いたします』と答弁する日が来るように」·「三階の奥から議場のすべての背中を見せていただいた」). 寺田 방청석 박수 불가 → **堀之内 「議員の拍手は会議規則に禁止はない。慣例は変えられる。二十五年の最後の任期に一回くらい」 → 大野·小西·森川·竹中까지 의원 박수**. **片岡: 의사록에 「拍手」 한 단어를 직접 기재**.
- 배지 반납. ひなた 「もう、ぎいんさんじゃ、ないの？」 → 「四月まで、ただのパパ」.
