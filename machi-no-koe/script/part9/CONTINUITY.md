# 第1話 「首班指名」 (2030-07-15 ~ 07-24)

## 확정 사실
- **7/15 연립 협의**: **民生党 代表 芦田 — 1차부터 「朝倉陽介」 기입(자기 이름으론 협화 이탈 20명이 못 씀), 「扉を開けたまま出て行った人だから信用できる」「政権交代は今しかない。協和党が鬼塚の手に戻ったら次は二十年ない」**. 平田(이탈 20명 정리역, 榊과 둘이): 「『豆腐屋の息子に入れた』と言える」. 大門: 3당 189 → 1차 과반 실패 → 결선은 다수결(과반 불요), 再生党 66은 백지 또는 千石 → 결선에선 무효.
- **연립 합의서(7/16)** = 위 고정 설정. 新会派명 **「改革保守の会」**. **大門: 「民生党を『数』として使うな。百三十八人全員の名前を覚えろ。与党の仲間の名前を忘れる総理は半年で倒れる」** → 佐野가 189명 명부(사진·선거구·중점 정책), 매일 아침 10명씩 암기. 早瀬 「永田町では名前は票です」 ↔ 篠原 「票の前に人です」.
- **7/20 美咲: 首相公邸 이주 거부 — 「ひなたの学校は砂町。北砂小、二年生。陽斗くんも。私の病院もここ」「総理の妻は仕事を辞めるものってみんな思ってる」 → 평일 공邸·주말 北砂, 「ひなたのトマトはここで育てる。陽介は帰ってきて水をやる」**. ひなた 「そうりって？」 「一番忙しい人」 → 「まいばんビデオする？」「じゃあいいよ、そうりなっても」. **美咲는 大庭에게서 鬼塚의 ひなた 학교 언급을 들음 — 「やめたら鬼塚の勝ち。でも怖い。一回だけ言わせて。……怖い。以上。冷めるわよ」**.
- **7/23 衆院 首班指名**: **1차 투표총수 465 — 朝倉 205 / 藤堂 義和(協和 新総裁) 191 / 千石 66 / 기타 3 → 과반 없음 → 결선 朝倉 vs 藤堂: 有効 398·白票 67 → 朝倉 208 / 藤堂 190 → 衆院 지명**(その他 25 중 16이 朝倉, 再生党 백지). **参院은 결선에서 藤堂 지명 → 両院協議会 불일치 → 憲法 67조 衆議院の優越로 朝倉 지명** — 参院은 3년 전 선거 그대로 = ねじれ 지속(법안이 参院에서 막힐 수 있음). 大門 「総理になる前からねじれだ。楽な総理にはならないぞ」.
- **町会館 TV**: 「豆腐屋の息子が総理に」 자막. 寺田 「あいつ町会の青年部長だったんだぞ。一年だけって約束で」, 吉岡 「台所で倒れてた俺を見つけたあの坊主が」 「町会館はほこりが多い」. **文子의 첫마디 「ご飯、ちゃんと食べてるかしら」** → 전화 「ご飯ちゃんと食べてるの」 「食べてない」 → 佐野 편에 木綿 2丁·醤油·東郷의 鰹節, **「総理大臣でもお腹はすくの」「明日の朝四時、店は開ける。総理の母でも豆は待ってくれないの」**.
- **SP 鷲尾 遼 첫 등장: 「了解。三点申し上げます」 — 이동은 전부 경호 차량(전철 불가), 가두연설·상점가 방문은 경호과와 사전 협의, 가족 경호 개시(자택·가게·통학) — 「以上。移動します」**.
- **22시 組閣**(위 고정 설정). 平田(国交) 「能登の『決める場』を私が作ることになるとはな」. 水野: 내일 7시 미 대통령 전화(통역 森 葵). 榊: 북한·중국 해경 동향 — 「最初の一か月、『何も起きない』とは限らない」. 雄大: 다음 주 **警察庁 柏木 組織犯罪対策部長 브리핑(関東湾龍会)**. **陽介: 「この内閣は『誰かがやる』内閣じゃない。『みんなでやる』内閣」「閣議でも一致しないことは隠さない。閣議決定は全会一致でいい。でも議論は残す。議事の要旨を公開する」**.
- **23시 취임 회견**: 「豆腐屋の息子です。明日朝四時、母は店を開ける。私は朝七時、大統領と電話。同じ朝です」, 가족은 北砂 잔류·美咲 救急 근무 계속, 최우선 3가지(3상자 예산화·반사회 자금 차단법 1년 내·동맹 기축+근린 대화), 「特定の議員の名前は言わない。証拠があれば警察と検察」, 중국 = 수산물 정지 철회 요구+정상 대화 재개(「扉は閉めない」), 「電車にはもう乗れないそうです」.
- **7/24 7시 첫 미일 정상 전화(통역 森 葵, 34)**: 대통령 「Congratulations」 + 「豆腐屋の息子が総理に、素晴らしい物語」 → **30초 만에 본론: 「関税と防衛費の話をしよう。日本の車の関税、日本の防衛費と在日米軍の駐留経費。来月ワシントンに来てほしい」**. 마지막에 「豆腐、今度食べさせてくれ」(농담) → 陽介 「本気で持っていきます。北砂の木綿を」.
