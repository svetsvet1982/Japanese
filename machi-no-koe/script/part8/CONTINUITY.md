- **綱領(A4 1장)**: ①保守でもリベラルでもなく、生活から ②名前のある一人一人を、ひとりにしない(石井 회파명에서 차용) ③一致しないことは一致しないと書く — 防衛増税 「中身が示されるまで保留、抑止・対話・避難を物差しに」 / 原発 「新設なし、既存は安全審査・使える避難計画・地元同意が条件、再稼働を急ぐ党員(雄大)と段階的に減らす党員(陽介)がいる」 / 外国人 「共生を進める。同時に治安や暮らしの不安を数字で示し正面から答える」 ④企業・団体献金を受け取らない、全収支を毎日公開 ⑤決めたふりをしない(水野의 말).

# 第1話 「新党」 (2030-01-06 ~ 01-08)

## 확정 사실
- 1/6 이사: 창가 = 5월 토마토 자리. **大地: 코로케 100개 「木村大地　個人」 영수증(「団体はだめ、個人で」)**, 雄大 「敵でした。今は同じそば屋の上です」.
- 篠原: 政党要件·交付金 基準日. 黒須: 補選 1구 2,500만 → 100명이면 25억. **早瀬: 「松平首相、通常国会冒頭の解散を見送り、予算の成立を優先」(북한 신형 미사일 실험 정보 + 중국과 수산물 전문가 협의 개시 → 「今は選挙をしているときではない」)**. 衆院 임기 잔여 1년 반, **6월 会期末 해산 유력** → 「半年、お金と組織を作る時間」. 新党 후보 찾기 최난관(낙선=무직).
- **田辺: 외부 감사(변호사·회계사, 区議 시절부터) 이상 없음 → 1/6부로 公設第一秘書 자진 사직(「新党の会見で反社の現金を受け取った秘書が後ろに立っていたら『寄せ集め』の上に『汚れた』」) → 亀戸로 돌아가 小川의 町会 見守り 지원, 4월 시행에 맞춰 「亀戸で一番最初の『手紙を置く』人」, 「残りの人生は『見る』方に」**. 「善処いたします。ですから、努力義務でございます」.
- **屋上(スカイツリーが少し)**: 雄大 협화당 離党届 수리. **鬼塚 전화 한마디 「久世の家も、これで終わりだな」**. 久世 隆은 침묵, 「亀戸の小川さんには自分の足で挨拶に行け」 → **小川 「隆先生の息子が豆腐屋と組むとはな」, 후원회 명부를 줌(「使うかどうかはあんたが決めろ」) → 雄大 「名簿じゃなく一人ずつ会いに行く」**.
- **1/7 회파 이탈 인사**: 「八か月、造反一回、処分二回」 「民生党の『反対』もみらいの『増税なき』も間違っていない。私はまだ決められない」 「扉は閉めません。開けたまま出ていきます」. **仁科 민생당 잔류, 4/1 見守り法 시행일에 北砂 町会館 방문 희망(福島의 어머니에게 사진)**. 大門: 江東에도 민생당 후보 가능성, 「ぶつかっても悪口は言うな」.
- 밤 신본부: ひなた 「したにおそばやさん」, 창밖은 옆 빌딩 벽 → 「トマト、おくじょうにおこう」. **文子: 가게 온도계 예비분 — 「毎朝見なさい。党の温度」**.
- 綱領 논의(위 고정 설정). 외국인 항목: みらい 의원 「千石の土俵に乗るのでは」 ↔ 陽介 「乗らないと千石さんに投票する人と話せない。海堂さんの五万票、二十代の一位を『差別主義者』と言って終わらせたら千石さんと同じ」. **篠原: 외국인 검거 건수는 20년 전보다 감소, 「不安を感じる」는 증가 — 숫자와 불안이 반대 방향**. 陽介 「鹿児島の工場にも行く。行ってから書き直すかもしれない」(→9화).
- **1/8 14시 결성 회견**: 雄大 무의석 幹事長 = 「党のお金と選挙の責任者。国会の中の取引に縛られない」. **「寄せ集めでは？」 → 陽介 「寄せ集めです。豆腐は大豆と水とにがりの寄せ集め。違うものが一つの型に入って固まると豆腐になる。ただ、寄せ集めは型が大事。私たちの型は第二項」**. 제3항 = 「割れていることを隠せば選挙のあとに割れる」. **宮本: 「政調会長の中身が『決めない』でいいのか」 → 「『決めたふりをしない』です。物差しは書いてある。公約で示します」**. 「くらしの声」は誰の声 → 「母、能登の漁師、福島の民宿、豊洲の仲卸、亀戸の町工場、まだ会っていない全国の人。半年で会いに行く」.
- 20시: **신당판 「透明な財布」 6시간 4,200건·840만 엔, 1호 「北砂　朝倉ひなた　三百二十円」(또), 2호 吉岡 1,000엔 「今度は木綿の五倍半じゃなくて六倍だ。また値上がりした」**.

# 第2話 「公約をつくる」 (2030-01-09 ~ 01-20)

## 확정 사실
- 벽에 포스트잇 214장(각각 제출자 이름). 黒須: 80쪽 공약집 읽는 유권자는 1,000명 중 1명, 나머지는 「一行」 → 「三つ」. 篠原: 버리지 말고 「3개 상자에 넣기」, 못 넣은 건 「今回は入らない」+**이유를 한 줄씩(早瀬: 「『検討』ではなく『順番』」)**.
- **3개 상자**: ①「ひとりにしない」(介護·保育·学童 처우, 高額療養費 多数回該当 유지, 孤立死 감소 — 60장) ②「見えない時間を仕事に。働く人を増やす」(待機時間·夜勤仮眠·ヘルパー移動, **年収の壁 해소** — 50장+雄大의 경제 20장) ③「逃げる場所と逃げる道」(防災·避難計画·国民保護, 제로미터·원전 주변·섬 — 40장). **雄大 비판: 「全部『守る』。『稼ぐ』がない」 → 早瀬: 「人手不足がこの国の経済の一番の壁。人が働ける時間を増やすのは成長戦略、地味だけど」 → 「人への投資」(雄大: 경산성에서도 썼지만 예산은 공장·반도체로)** → ②번 이름에 「働く人を増やす」 추가.
- **재원 적산(3일째 밤 컵라면)**: ① 연 1.8조 ② 年収の壁 税額控除 방식 연 2.4조(待機時間은 주로 운임 제도) ③ 연 0.9조(처음 5년) → **합계 연 5.1조 엔**(방위비 3% 6조와 비슷). 재원 = **租税特別措置 재검토 2조 + 金融所得課税 1.2조 + 3년 기한 つなぎ国債 1.9조**. 黒須 「数字は合っている。でも一行にならない」 ↔ 篠原 「財源を書かない公約は千石の消費税ゼロと同じ」 → 黒須 「両立はする。順番がある。先に一行、あとで数字」. 남은 44장 = 「まだ会っていない人の名前」 → **20일엔 「骨」, 살은 현지에서(能登·福島·北海道·大阪·沖縄·鹿児島)**.
- **1/13 ひなた 작문 숙제 「わたしの　まちの　いいところ　みっつ」 → 기준 「なくなったら、いちばん、かなしいもの」: ①おとうふやさん ②ランちゃんとよしおかさん(ふたりでひとつ) ③こうばん(매일 학교 앞에 서는 경찰관 — 大庭 쪽 경계)**. 文子 「お店と、お店に来る人。両方」.
- **1/15 西尾 교수**: 租特 2조는 다소 낙관(업계 저항으로 반감 가능). **「金利のある世界」 — 日銀 금리 인상 중, つなぎ国債에도 이자(연 수백억) → 재원에 명기**. 「入らないものは理由を書く」 칭찬 — 「全部入れて全部やらない」 「約束は少ないほど守れる。数えられない約束は約束じゃない」.
- **1/17 상자 이름 재정의**: ①人と人のつながり ②働く場所と働く人(文子) ③安全은 「毎朝そこにいる人」(ひなた의 交番) — 방위는 ③ 안에 「抑止と対話と避難」, **3%는 「中身を示すまで保留(党内に賛成と保留がある)」, 단 자위관 처우·탄약·숙사(継戦能力)는 찬성·재원 별도 제시**. **一行 = 「名前を忘れない政治」**(补선 마지막 밤 「名前を忘れる政治家にはなりたくない」에서, 黒須 「覚えられる。十文字」). 남은 44장: 31장 「現地で聞いて決める」, 13장 「財源を示せないので見送る」.
- **1/18 陽介, 탈락 13장 제출자 13명에게 직접 전화(3시간)** — 화낸 사람 2명, 11명은 전화 자체에 놀람. 大阪 상점가 사업승계 세제 우대를 낸 젊은 후보 예정자(大阪 선거구 출마 고민) → **3월 함께 상점가 걷기로**(→6화). 黒須 「普通は秘書がメールで『総合的に判断しました』」.
- **1/20 공약 발표 회견**: 「名前を忘れない政治」 + 3개 약속, 연 5.1조, 재원 10쪽(つなぎ国債 이자 포함 「金利のある世界なので」), 「三つなら四年後に数えられる」, 마지막 쪽에 탈락 44항목과 이유. 宮本 「選挙まで公約が変わり続けると」 → **「骨は変わらない。肉は会いに行ってつける。変わったところは全部日付をつけて公開」 → 宮本 「『透明な公約』ですか」 「それ使わせてもらっていいですか」**.
- 밤: 文子 「私の言葉が国の公約に？お代もらわないと」 「冗談よ」, 吉岡 「俺の名前入ってるか」 → 「一番最初の名前」. **ひなた 작문 はなまる**.
