# 대본 집필 가이드 (『まちの声』 모든 화 공통)

견본: `script/part1/ep01.md` — 반드시 먼저 읽고 형식·밀도·톤을 그대로 맞출 것.
설정: `plan/00_series_bible.md`, `plan/0N_partN.md`

## 파일
- 경로: `script/partN/epXX.md` (XX = 01~15, 두 자리)
- 각 부 폴더에 `script/partN/CONTINUITY.md`(연속성 메모)를 두고 한 화를 마칠 때마다 갱신한다:
  새로 등장한 인물(이름·읽기·나이·말투), 확정된 사실(숫자·날짜·장소), 회수해야 할 복선, 다음 화로 넘긴 훅.

## 형식
1. 제목: `# 第N部 『부 제목』 第X話 「화 제목」（한국어 제목）`
2. 정보 표: 턴 수 / 작중 날짜 / 등장인물 / 구성(7구간과 턴 범위) / 일상 장면 / 시사 포인트
3. 필요하면 `> 등장인물 관계 메모:` 한두 줄
4. 본문: `## ① 일상 오프닝` … `## ⑦ 엔딩`, 구간 사이에 `---`
5. 장면 표시: `【場面：장소／시간】`
6. 대사: `NNN 話者：台詞` (NNN = 001~180, 세 자리, 한 줄에 한 턴, 빠짐·중복 없이 정확히 180턴)
   - 화자 표기는 성 또는 이름(陽介·美咲·文子·寺田·篠原·ラン 등) 또는 역할(救急隊員、指令員 등)
   - 지문·내레이션·괄호 속 동작 설명은 쓰지 않는다. 행동은 대사 속에서 드러낸다.
7. 마지막에 `## 어휘·표현 노트` (표, **일상 10개 이상 + 시사 10개 이상**, 한국어 설명)
   + `### 말투 포인트` (4~6개 불릿) + `### 이번 화의 핵심 문형` (3~5개, 예문 포함)

## 180턴 7구간 (±5턴 조정 가능)
① 일상 오프닝 1–20 / ② 생활·직장 21–45 / ③ 문제 발생 46–75 / ④ 현장·청취 76–105 / ⑤ 회의·토론 106–140 / ⑥ 전환·클라이맥스 141–170 / ⑦ 엔딩 171–180
- ①②⑦은 어느 부에서도 일상 회화 중심.
- ⑤는 시사 어휘를 집중 배치한다. 해당 부 기획서의 「토론 표현」 표에서 최소 3개를 쓴다.
- ⑥에는 4~6문장짜리 긴 발화(고백·연설·질의)를 최소 2개 넣는다.
- 마지막 턴(180)은 질문이나 충격으로 끝내 다음 화로 이어지게 한다.

## 내용 원칙
- 해당 부 기획서의 그 화 줄거리를 충실히 따르되, 대화로 구체화하면서 디테일(가격, 숫자, 지명, 제도 이름, 서류 이름)을 채운다.
- 앞 화의 엔딩 훅을 다음 화 일상 오프닝에서 받는다.
- 일본어는 자연스러운 현대 표준 일본어. 인물별 말투(바이블 참조), 경어 수준 차이, 下町 말투, 방언, 학습자 일본어(ラン 등)를 살린다.
- 시사 내용은 **찬반 양쪽의 논리를 공정하게** 대사로 준다. 주인공이 늘 옳은 것으로 처리하지 않는다(특히 외국인 정책·재정·안보·원전).
- 폭력단의 협박·발포, 9부의 습격은 결과와 반응을 대사로만 보여 준다. 무기·입수 경로·실행 절차·경호의 허점은 쓰지 않는다. 실제 요인 습격 사건의 고유한 디테일은 차용하지 않는다(`plan/09_part9.md` 「묘사 원칙」 참조).
- 실존 정치인·정당·기업·단체 이름은 쓰지 않는다(가공 이름만). 실제 제도·법률·지명·통계 기관 이름은 써도 된다.
- 통계 숫자는 「작중 설정」임을 의식하고, 실제 수치를 쓸 경우 집필 시점에 확인한다.
- 각 화 길이: 본문 대사 약 7,000~11,000자.
