# 第2話 「質問のつくり方」 (2027-05-14 ~ 05-25)

## 확정 사실
- 6월 정례회 일반질문: **회파 持ち時間 30분(답변 시간 제외) → 陽介·石井 15분씩**. 통고 마감 **5/21(금)**.
- 美咲(야근 후)의 빨간 펜: 간호 기록 인계 원칙 「一番大事なことは三行目までに」 → 1행 = 「この質問で、区に、何をさせたいのか」.
- 大野의 수업(控室, 인스턴트 된장국): 일반질문의 목적 = **「答えを、議事録に残させる」**. 「通告は大きく、質問は小さく」. 片岡: 통고서엔 항목과 답변 상대(区長/教育長)만, 통고에 없는 것은 질문 불가 → 이후 **聞き取り**.
- 聞き取り·答弁調整 논쟁: 石井 「八百長」, 大野 「学芸会と呼ぶ人も」. 조정에 응하면 「前向きに検討」, 안 응하면 「研究してまいります」. **大野는 20년간 거의 응하지 않음** → 약한 답변, 그러나 강한 議事録.
- **三階の奥 답변 해독표**: 研究=거의 안 함 / 検討=지금은 안 함 / 前向きに検討=예산·조정 남음 / 方向で調整=거의 결정 / ご指摘を踏まえ=체면 / **注視してまいります=우리 일 아님, 보고는 있음**(大野가 추가).
- **5/19(수) 17:12 大地·真奈美의 아들 「木村 律(りつ)」 탄생**, 3,100g, 예정일보다 하루 빠름, 東陽町 산부인과. 진통 14시간, 大地 울었음(부정). 이름 = 규칙·리듬, 木村精肉店 70년의 리듬. 大地 아버지 울음.
- **北砂小 2층 화장실**: 区 학교 수선 대기 **300건 이상**, 北砂小 **築50年**. 真奈美 「その『一つ』が、何百個もあるから、大きい話になる」.
- **陽介 통고 = 2항목**: ①孤独・孤立対策と災害時の要配慮者支援 ②防災について(안에: 個別避難計画 작성률·공표 / 江東5区 広域避難 / **国民保護**). 물류·학교 등은 보류.
- **権田에게 전화**: 「当たり前だ、バカ野郎。十五分で全部しゃべる議員なんか誰も信用しねえ。でも、九月には、必ずやれよ」 → **9월 정례회에 물류(트럭 대기) 질문 약속**.
- 국민보호 문제의식: 1부 방재회의 중 J-ALERT 시험 방송 때 寺田 「戦争のときは、どこに逃げりゃいいんだ」. 수해 = 区外로(250만 명) vs 무력공격 = 근처 견고한 건물로 → **태풍과 미사일 경보가 겹치면?** 国民保護計画은 区市町村 작성 의무 → 「計画同士の矛盾」은 区에 물을 수 있다. 질문 여부는 당일 판단.
- 5/24(월) 聞き取り: **青木(福祉部 地域福祉課長)** — 작성률 수치 「精査中」, 수치를 빼면 「前向きに検討」 제시 → 陽介 거절(「数字が出ないと、来年、増えたか減ったか、誰にもわからない」) → 「上に相談」. **高橋 修平, 4월부터 防災課長**(「本当に質問しに来るとは」), 수치는 자신이 青木에게 내도록 말하겠다. **沼田(危機管理室長)**: 국민보호는 危機管理室 소관, 「不必要な不安」「国で検討中」 → 본회의에선 신중히.

# 第3話 「初めての一般質問」 (2027-06-09)

## 확정 사실
- 6/9(수) 第二回定例会 일반질문. 陽介 3번째(14:35 登壇), 石井 2번째(구청 신청 시스템 디지털화 — **도장란 이미지를 의장 모니터에 띄움** = 「見せる人」).
- 文子 豆腐店 **오후 휴업**(남편 사망 이후 처음). 주먹밥 梅·おかか(「今日は勝負の日じゃなくて、仕事の日」). 寺田 「てめえの言葉で、しゃべれよ」. 寺田는 区議会 의장 내부 첫 방문(陳情은 복도까지).
- 방청 규칙: 이름·주소 기입, 박수·발언·촬영·녹음 금지, 휴대폰 끄기. 吉岡은 맨 앞 통로 쪽(난간).
- 大野 조언: 「登壇したら、まず、傍聴席を、一回、見なさい」.
- **一括質問**(원고만 읽음, 방청석 안 봄). 文子: 어릴 때 피아노 발표회에서도 악보만 봄.
- **区長 답변: 個別避難計画 대상 약 12,000명, 작성 1,104명, 작성률 9.2%(4/1 기준)** — 공식 수치 첫 공표. 매년 공표는 「検討してまいります」. 広域避難 「連携を図りながら、引き続き、しっかりと」.
- 野次: **竹中(協和党)** 「短いな」「傍聴席を、使うなよ！」「不安を、あおるな！」, **真壁(再生党, 区議会 再生党 1석)** 「泣き落としで、取るのか」「区議会で、戦争の話か！」.
- **再質問(자기 자리, 원고 없이)**: 「十人のうち九人には計画がない」 → 吉岡 이야기(방청석 언급 → **議長 松岡 주의**) → 「来年度から実施を」 → **区長 「来年度からの実施に向けて、前向きに検討してまいります」**(검토 → 前向き + 시기). 大野: 시기가 들어간 답변은 내년에 「どうなりましたか」로 물을 수 있다.
- **国民保護 재질문**: 태풍 広域避難 중 J-ALERT 미사일 정보 시 「外へ逃げるべきか、中にとどまるべきか」, 「両計画は整合しているのか」 → 区長이 **沼田에게 답변 넘김** → 답변서에 없어 정지 → **「具体的な調整は、行われておりません」**(議事録) → 「注視しつつ、整合性について、確認してまいります」. 陽介 마무리: **「一年後、確認の結果を、改めて、この場で、伺います」**(→ 2028년 6월 재질문 약속).
- 寺田: 박수 대신 등을 펴고 고쳐 앉음(「立ってねえ。座りなおしただけだ」).
- 控室: 大野 「答弁者が答弁書なしで本当のことを言うのを、二十年で初めて見た」. **高橋 전언: 沼田는 3년 전부터 이 문제를 위에 올렸으나 「国の動向を見てから」로 묵살 → 「本会議で聞かれなければ、庁内で誰も動かなかった」 감사**.
- 堀之内: 재질문은 「悪くなかった」, 단 방청석 언급은 다시 하지 말 것 — **「松岡くんは、根に持つよ」**.
