# 대사 문체 수정 가이드 (2부~9부 공통)

목표: 「……」 남발과 문절마다 찍힌 「、」를 걷어 내고, 짧은 문장과 긴 문장이 섞인 자연스러운 일본어 대사로 고친다. **기준 문체는 1부(특히 `script/part1/ep05.md`)**.

## 반드시 지킬 것 (구조는 손대지 않는다)
- 턴 수 180, 번호(001–180), 각 번호의 화자, 장면 표시 【場面：…】, 헤더 표, `## ①`~`## ⑦` 구간 표시는 그대로 둔다. 턴을 합치거나 나누거나 추가·삭제하지 않는다.
- 내용·사실·이름·숫자·날짜·인물의 말투(吉岡의 거친 말, 藤崎의 「〜っす」, 文子의 「〜わよ」, 관료·국회의 경어 등)는 유지한다.
- 대사 안에 괄호·지문을 넣지 않는다. 영어·중국어 대사는 앞의 「……」만 지우고 내용은 그대로 둔다.

## 「……」
- 턴 첫머리의 「……」는 기본적으로 지운다.
- 남겨도 되는 경우: 침묵 턴 「……。」, 말을 잇지 못하는 감정 장면(「陽介……。」「……っ……。」), 말끝을 흐리는 경우 한 번 정도.
- 목표: 한 화 평균 **턴당 0.6개 이하**.

## 「、」와 분절
- 수식어와 명사 사이, 명사와 조사 사이, 한 덩어리 구 안에는 「、」를 찍지 않는다.
  - ✗ 「お母様が、受けた、電話から、ご説明、します」 → ✓ 「お母様が受けた電話から、ご説明します」
- 「、」는 주제가 긴 문장의 주제 뒤, 절과 절 사이, 나열, 감탄사·호칭 뒤 정도에만. 목표: **턴당 1.5~3개**.
- 「……」로 잘게 끊긴 조각들은 접속 표현(〜て、〜から、〜ので、〜けど、〜のに、〜ながら、〜たら、연체수식절)으로 이어 한 문장으로 만든다.

## 문장 길이의 변화
- 짧은 맞장구·감정 표현은 짧게 둔다.
- 설명·보고·설득·연설·회상은 2~3개의 절을 이은 긴 문장(40~80자)도 섞는다. 한 턴이 모두 단문의 나열이 되지 않게 한다.
- 아이(ひなた)의 말은 히라가나 위주 그대로 두되, 단어마다 「、」를 찍지 않는다.

## 예시

| 수정 전 | 수정 후 |
|---|---|
| 柏木：……総理、お母様が、受けた、電話から、ご説明、します。……図を、ご覧ください。……「金の、川」と、呼んで、います。 | 柏木：総理、お母様が受けた電話からご説明します。こちらの図をご覧ください。私たちは「金の川」と呼んでいます。 |
| 柏木：……上流。……電話を、かける、場所。……東南アジアの、ある、国の、国境の、近くの、建物。……「詐欺の、拠点」。……そこで、何百人もが、毎日、日本の、高齢者に、電話を、かけて、いる。 | 柏木：まず上流、電話をかける場所です。東南アジアのある国の、国境近くの建物で、「詐欺の拠点」と呼ばれています。そこで何百人もが、毎日日本の高齢者に電話をかけているんです。 |
| 陽介：……海外から……。 | 陽介：海外から……。 |
| 早瀬：……受け子は、毎年、何千人も、捕まって、いますよね。……でも、被害は、減らない。 | 早瀬：受け子は毎年何千人も捕まっていますよね。それなのに、被害は減らない。 |
| ひなた：……パパ、きょう、がっこうで、「ほうあん」って、ことば、ならった。 | ひなた：パパ、きょうがっこうで「ほうあん」ってことばをならったよ。 |
| 文子：……陽介。……来たの。……靴、脱いで、入りなさい。……作業場、濡れてるから。 | 文子：陽介、来たの。作業場が濡れてるから、靴を脱いで入りなさい。 |
| 美咲：……。 | 美咲：……。（침묵 턴은 그대로） |

## 화 끝의 노트
- 「말투 포인트」「핵심 문형」 등에서 대사를 인용한 부분은 고친 대사와 맞게 「、」「……」를 정리한다. 한국어 설명은 바꾸지 않는다.

## 검사
`python3 script/check_style.py script/partN/epXX.md` — 턴 수·번호·화자가 원본(git HEAD)과 같은지, 괄호가 없는지, 「……」·「、」 밀도를 출력한다.
