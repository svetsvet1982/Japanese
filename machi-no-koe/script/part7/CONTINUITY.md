# 第1話 「初登院」 (2029-05-01)

## 확정 사실

- 국회 정문은 닫힘(총선 후 初登院 등 특별한 때만) → 옆 문으로, 佐野 영상 「横から入る一年生」. **黒須는 문 앞까지(20년 전 藤代도 이곳에서 배웅)**. 衛視·事務局 안내: **登院表示盤 버튼**, **議員バッジ(紫の地に菊, 국회 내 신분증, 분실 시 재교부) — 「軽い」「重くなるのはこれから」**, 712호 열쇠.
- 712호: 텅 빔(책상·의자·전화·빈 책장). 公設秘書 3명(政策担当·第一·第二) + 私設. 政策担当秘書 = 국가시험 또는 경력 심사 인정. **募集 4일에 120명 응모**.
- **복도에 陳情 12개 그룹(건설업 단체·トラック協会·医師会·電力会社·介護事業者団体 등)** → 전원 면담 10분씩, 수토산 거절, **「お話は伺います。お約束はしません。面会の記録はネットで公開します」**. トラック協会 사람 「若林さんの話を聞きました」.
- **歳費 월 129万4千円, 調査研究広報滞在費 월 100만 엔(사용처 공개·잔액 반납 규칙)** → 사무국 보고보다 세밀하게 1엔 단위 월별 공개.
- **早瀬 면접**: 사직 이유 「答弁書を書くのに疲れました」 — 전날 밤 질문통고 → 새벽 5시까지 작성, 17년, 「何も約束しない文章を一番上手に書けるようになった」. **江東区議会 의사록 전부(3일) 읽음 — 31항목 「やる」12·「検討」14·「わからない」5까지**. 「読む人と書く人が組めば少しは速くなる」. 해독: **「前向きに検討」= 省内では「やる方向で調整」(예산은 별개), 「検討します」= 今年はやらない, 「研究します」= たぶんずっとやらない**. 질문 1줄·답변 3장, 그 절반은 「聞かれたら困ること」 회피용. 조건: **「先生」と呼ばない・呼ばせない**.
- **田辺 면접**: 久世 隆 사직·雄大 낙선 → 사무소 다음 달 폐쇄, **雄大 지부에는 남지 않음(「父のやり方はもうやらない」는 雄大에게 자신은 방해)**. 자신의 일 = 亀戸 아케이드 보조금·口利き·후원회 여행·盆暮れ 인사 = 「古い政治」. 법 위반 없음, **久世 사직 원인 수지보고서 건은 담당 아니었으나 「知らなかったとは申しません」**. 결심 계기 = **小川(亀戸 후원회 지부장, 田辺가 30년 돌본 사람)이 개표소에서 陽介에게 고개 숙임**. 강점: 永田町 段取り(위원회 자료·회의실 예약·각 성청 연락처), 江東의 얼굴(亀戸·大島·東陽町 80대 이름). **「先生」 버릇 30년 → 「善処いたします」**.
- 토론: **黒須 반대 — 「つながりの全部が田辺さんを知っている。金の話を持ってくる人間が田辺さんを入口にするかもしれない」**(→ 12화 복선). 篠原 찬성(段取り 모르면 3개월 허비). 佐野 「嘘をつけない人」. 早瀬는 「霞が関の手先」 비판 예상되나 黒須도 찬성 — 「官僚は辞めた瞬間にただの人。古い秘書は辞めてもつながりが残る」.
- **雄大 전화**: 「誠実。父の秘書の中で一番几帳面で一番地元を歩いた人」 「ただ、父の周りにはいろいろな人がいた。私も全部は知らない。田辺さんはたぶん全部知っている」 「力になるか重荷になるかは朝倉さん次第」.

# 第2話 「会派に入る」 (2029-05-02 ~ 05-09)

## 확정 사실
- 5/2 8시 田辺 첫 출근: **亀戸 くず餅 3,240엔 영수증 지참(장부 기재)**, 「先生」 버릇 → 早瀬가 「朝倉さんです」로 교정. 早瀬는 후생성 시절 철야 후 くず餅을 먹었음. **명함 500장: 앞 「衆議院議員　朝倉陽介」, 뒤 「透明な財布」 QR·면회기록 페이지·작게 「北砂　朝倉豆腐店」(文子 허락 「宣伝になるならいいわよ」)**. 의원회관 접수처에 50장 맡김(田辺의 段取り). **田辺는 藤代를 앎(20년 전 久世와 같은 시기 국회)**.
- 브리핑: **국회법상 의원은 전원 상임위 최소 1곳 소속**(무소속도), 질문 시간은 회파 인원 비례·무소속은 「その他」로 몇 분, **일정·순서는 委員会 理事会(회파에서 이사 — 무소속은 없음)**. 상임위 17개 + 특위(재해대책 등). 陽介 희망 = 国土交通 + 災害対策. 篠原: 정당 vs 회파(의원에 신고), **統一会派 = 「民生みらい・無所属の会」, 衆院 98명, 野党第一会派** — 원전·안보 정반대지만 이사·질문시간 위한 「数」. 「数には値段がある」(会派拘束·党議拘束).
- **의원회관 지하 직원·비서 식당 카레 650엔** — 陽介 「秘書の話が聞けるのでここに来ます」, 田辺 「三十年で初めて聞くご希望」.
- **5/7 大門(民生党 国対委員長) 조건 3개**: ①본회의·위원회 채결은 회파 결정에 따름 ②질문 시간·순서는 국대 배분, 타 회파와 독자 거래 금지 ③회파 방침과 다른 발언은 사전 국대 상담. **安保·憲法 「本人判断」 예외 → 「認めない」**(한 명 예외 시 회파 분열 — 「割れた野党は与党に一番喜ばれる」, 「有権者に約束したのは君だ。会派じゃない」). 국대 = 매일 여야 국대 거래(심의 연기↔참고인, 채결일↔총리 출석) — 「取引のテーブルに座れない者は、自分の法案の日を決められない」. **가입 시 国土交通委員会 자리 보장(「一年生には破格」), 요구는 「数」=一票**.
- 橘: **みらい = 12명**, 단독으론 이사도 못 가짐, 安保 채결에서 민생당과 같은 패를 넣을 때마다 지역구에서 「裏切り者」 — 「数の値段はみらいも払っている」.
- **5/8 秋山 正和(무소속 5선, 衆院 第一議員会館, 田辺와 구면)**: 무소속 질문은 연 2회·1회 10분, **議員立法 찬성자 20명(예산 수반 50명)**, 무기 = **質問主意書(의장 경유, 내각은 원칙 7일 이내 閣議決定 答弁書)** — 5선 동안 300건. 예: 「全国の孤立死の数を国は把握しているか」 → 「網羅的には把握していない」 → 3년 후 국가가 처음 통계 시작. 「ああいう名前(吉岡)を主意書に書け」. 「お答えすることは困難である」도 기록으로 남는다. **1기째 회파 소속 → 조반 → 처분 전 스스로 탈퇴, 매일 후회**. 「私の真似はするな。君は『中で変える』に向いている。豆腐屋は店の中で豆腐を作るんだろう」.
- 사무소 토론: 早瀬 수치(가입 시 국교위 질문 연 4~5회·15~20분, 찬성자 모으기 쉬움 / 미가입 시 연 1~2회, 主意書·채결 자유). 佐野: SNS 「無所属を貫いて」. 篠原: 추천 양당 회파 가입은 자연스러움, 미가입+협의만 = 「いいとこ取り」. **田辺: 久世 隆은 派閥 결정으로 반대 법안에 白票 → 귀가 차에서 침묵, 口癖 「数がなければ何もできない」**. **早瀬: 관료가 가장 두려운 건 회파 안에서 「ここだけは譲れない」고 국대에 말하는 의원(조문 한 줄이 바뀜), 밖의 반대는 답변서 한 장으로 끝**. **黒須: 「『どこまでなら従えるか』ではなく『どこからは従えないか』를 먼저 말하라 — 선을 말하지 않고 조반하면 だまし討ち, 말하고 조반하면 約束どおり」**. 陽介 「安保はまだ知らない」 ↔ 早瀬 「知らないものに線は引けない」.
- 밤 美咲: 간호부 主任会 — **야근 인원 감축안에 끝까지 반대, 결정 후에도 기록을 계속 → 반년 후 원상복귀** — 「外に出て文句を言うより、そっちの方が効く」.
- **5/9 東陽町 喫茶「白樺」 藤代**: 陽介 크림소다, **藤代는 처음으로 ホット紅茶(「冷たいものがちょっと」), 야윔(「年寄りに痩せたって言うのは褒め言葉」), 기침 「春の風邪が長引いて」** → 7부 14화 복선. **大門은 藤代 2기째 비서**. **20년 전: 労働者派遣法 改正에 회파는 「修正で合意」 → 藤代(조합 출신) 青票 → 처분 → 무소속 출마·당선(野口·黒須 포스터) → 마지막 1기 질문 연 2회·법안 0개**. 「青い札は後悔していない。後悔は、外に出てから怒っているだけの人になったこと — 怒りで始めて怒りで終わった」. **「入りなさい。入って、中から変えなさい。青い札を入れる日が来たら、入れる前にちゃんと言ってから」**(黒須에게 가르친 것도 자신).
- **5/9 13시 大門에게 가입 통보**: 조건 전부 수락 + **「従えない採決が来たら、その前に必ず大門さんに言い、理由を言って処分を受ける。隠れて休んだりトイレに行ったりしない」** → 「造反の予告付きで入る一年生は初めてだ」. **20년 전 藤代도 같은 말을 했고 실제로 했다, 大門이 처분을 전하는 역할 — 「俺に二度目をさせるなよ」**(→ 7화 党議拘束).
- 17시 회파 총회: 인사 「違う意見を言うときは、この部屋の中で言います」. 野口: **회파 총회 명물 幕の内 1,200엔(회파 회비) — 영수증 요청 → 「黒須の仕込みだな」**. **배정: 国土交通委員会 + 災害対策特別委員会**.
