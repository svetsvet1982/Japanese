# 第3話 「レク」 (2029-05-10 ~ 05-14)

## 확정 사실
- 5/10: **ミニトマト 노란 꽃**. 田辺: 레크는 2층 회의실(응접실은 3명이면 좁음), **차는 페트병(湯呑み면 관료가 「長居していいのか」 망설임)**, **컵라면 20개 박스 구매**. 早瀬: 레크 = 설명의 장 + 「この議員は何を聞いてくるか」 탐색의 장(반응·메모가 성청에 보고됨) → 陽介 「隠し事はなし」.
- **国土交通省 物流・自動車局 課長補佐 戸田 / 係長 仲村 / 係員**. 법안 **「貨物自動車運送事業法等の一部を改正する法律案」(가공)**: ①국가가 「適正な原価」 제시·하회 운임 계약 방지 ②**多重下請け 시정 — 재위탁 2회까지 「とどめるよう努める」(노력 의무, 벌칙 없음, 대신 지도·조언)** ③**荷主의 「待機時間等」 부담 시정 — 「等」의 범위(荷役·付帯業務 등)는 省令으로**. 대기 시간 국가 조사 = **수년 전 것, 지금은 「業界団体を通じて把握に努めて」**. 陽介 「とてもよくわかりました。わからないことが」.
- 早瀬 번역: 努める=벌 없음, 지도·조언=お願い(→勧告→命令·罰則의 4단계), 「図られるものと考えて」=주어 없음, **「等」= 범위 결정은 관청**, 「詳細は省令で」=관청에 맡겨라, 「実態を踏まえて適切に」=업계와 상담·내용 비공개(「荷主業界が反対したら狭くする」), 「業界団体を通じて」=스스로 안 조사. **노림수 = 국가가 스스로 실태조사를 하는가 + 언제까지** → 조사 수치 = 다음 개정에서 「努める」→「しなければならない」의 **立法事実**.
