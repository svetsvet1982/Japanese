## ep01 「苗字をどうする」(2026.1.3 土 ～ 1.10 土) 확정 사항
- 새 인물(이름 없음): **住民**(窓口, 女性, 20代後半, 本籍 北海道, 来月 婚姻届 제출 예정, 仕事では今の名字を続けたい). 새 고유명 없음.

- 새 설정
  - 1/1 夜中 航·遥 전화로 새해 인사. 遥는 연말연시 ことのは書房 初売り 준비. **遥가 연말에 剛·恵子에게 약혼을 전화로 알림**(剛 반응은 미묘사), 菜摘에게는 航이 **LINE 한 줄 「婚約した」**.
  - **1/3(土) 午前10時 阿佐ヶ谷神明宮 初詣**: 修一도 元日에 걸어서 참배. 遥의 소원 「ちゃんと話せますように」. **おみくじ 「吉」 「縁談：急がずともよし。よく話し合うべし」**(112에서 遥가 회수).
  - **1/3 午後1時 早瀬家 正月 — 정식 결혼 보고**(典子·修一·菜摘·拓也·心春·蒼太). 遥 手土産 = 堺の母が送ってきたお菓子. 拓也 「やっと『お義姉さん』」. 心春 「はやせはるかちゃん？」. **菜摘: 결혼으로 早瀬→宮内, 名義変更(銀行·カード·免許) 끝날 때까지 2か月**. 拓也 「普通、そういうもんじゃない？」. **典子 「名字なんて、どっちでもいいじゃない」**, 修一 「駅の名前が変わっても…そのうち慣れる」.
  - **遥의 「白石」(새 설정)**: 出版社の営業·注文電話 모두 「白石」, **地域のフリーペーパー에 月1回 「書店員・白石遥の今月の一冊」 연재 3年째**(航은 窓口のラック에서 매달 가져가 읽음, 先月 = 雪の日に読む短編集), **POP 끝에 작게 「白石」 서명**, 「十年かけて覚えてもらった名前」. 바뀌면 손볼 서류: 銀行2つ·クレジットカード·携帯·パスポート·運転免許(ペーパー)·店の社会保険·年金·マイナンバーカード. 遥 「絶対変えたくないわけじゃない、同じ名字がうれしい気持ちもある、『普通』で決まるのが嫌」.
  - **航의 자각**: 자기 성이 바뀔 가능성을 「一回も」 생각한 적 없음 — 「考えてもいなかった」.
  - **1/6(火) 窓口 — 婚姻届·旧姓 설명(이 화의 기준)**: 用紙는 戸籍の担当窓口, 窓口에 記入例 있음 / 証人 = 18歳以上 2人 署名 / **2024年3月から戸籍謄本 원칙 불필요**(念のため戸籍担当에 확인) / 夜間·休日 = お預かり / 「婚姻後の夫婦の氏」 欄 「夫の氏／妻の氏」 / 旧姓併記 = 婚姻後 旧姓이 실린 戸籍謄本 등으로 住民票 請求 → マイナンバーカード·運転免許証(警察)·パスポート(申請時) 併記 가능, **銀行·カードは金融機関ごと**. 「名字を変える方に手続きが集まりやすい」.
  - 1/6 昼 休憩室: 航이 美咲·グエン·大森에게 약혼 보고. 의견 — **美咲: 友達が別姓のため事実婚, 「同姓義務は日本だけと言われてる」** / **グエン: ベトナムでは結婚しても名字は変わらない, 子どもは普通父の名字** / **大森: 「家族の名字は一つのほうがまとまる」意見もわかる, 家内는 결혼 30년, 同窓会で旧姓で呼ばれると「若返る」**(새 설정) / 航: 約95%が夫の名字, 別姓 논의 30年, 旧姓 通称使用 법제화 방향 논의, 「まだ何も決まっていない」.
  - 1/6 夜8時半 ことのは書房 閉店後: 해외 사례(韓国·中国 = 変わらないのが普通, アメリカ·イギリス = 本人が選ぶ, ドイツ = そろえても別々でも·つなげる人も). 遥 「白石早瀬？　長っ」. **航의 실언 「そんなに困らないんじゃないかな」** → 遥 「困るかどうかは困る人が決める」「『ご本人が決めることです』って窓口で言うてるやん」 → 서로 사과.
  - **剛(전화, 恵子가 바꿔 줌) 반대**: 「嫁に行くんやったら向こうの名字」「名字がばらばらで生まれてくる子どもはどうすんねん」「東京のに『白石』を名乗らせる気か。向こうの親御さんに顔向けできるかい」 → 遥 「なんでお父ちゃんが決めんの！　うちらのことやんか！」 → 剛 「好きにせえ。わしは知らん」 工場へ. 剛→航 호칭 여전히 「東京の」. 航은 전화로 新年 인사·사과.
  - **1/10(土) 午後2時 早瀬家 — 典子의 이야기(새 설정)**: **教師 2年目に結婚, 始業式で「名前が変わります」→ 男の子が「前の先生はどこに行ったの」と泣いた**, 出席簿·印鑑·通帳을 혼자 고침, 修一는 아무것도 안 함(「乗務が…」). 「どっちでもいい = どっちを選んでもあなたたちの家」「どうせ決めるのはあなたたち」. 修一 「車両の番号が変わっても、運転台に座るのは同じ運転士だ」. 修一가 遥의 「堺の電車の話」를 기다림 — **堺の実家近くを路面電車が走る**(遥가 사진을 보여 주기로).
  - **해결 — 「決め方」을 먼저 정함(1/10 夕方 中杉通り)**: 航 「俺が白石になる」도 본심으로 하나의 안, 遥도 「早瀬になる」를 하나의 안으로. **婚姻届の記入例の裏に書いた3원칙: 「一、ふたりで決める。二、決めたら、二人で話しに行く。三、手続きは半分こ」**(親の意見は聞く、決めるのは二人 / 両方の親に二人そろって説明 / 名義変更は手分け, 平日の銀行は航が半休で付き合う). **기한 = 婚姻届を出す日まで, 「急がずともよし」**. **어느 성으로 할지는 미결정**(→ 15화 「二人が決めた方式」).
- 1/10 夜7時 福来軒: 大輔 ギョーザ おごり. 恵子 LINE 「お父ちゃん、あの晩から『東京のは何て言うとった』って、もう三回聞いてきた」 → 航 「二人で決めて、二人で説明しに行きます」 전언 부탁. 大輔: 常連の若いのが更新で家賃を上げられた, 「名字より揉めるかもな」.
