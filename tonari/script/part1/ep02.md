## ① オープニング

【場面：高円寺・柳田荘の玄関／4月2日（火）朝7時40分】

001 高木：あ、早瀬さん、おはようございます。昨日の荷物、朝になってもやっぱり出てこないんですよ。
002 航：おはよう。植木鉢の裏とか、自転車置き場のほうも見た？
003 高木：見ました。郵便受けの上も、階段の下も。配達完了のメールには、ちゃんと「玄関前に置きました」って書いてあるのに。夜中に一回、もう一回朝起きてすぐ探したんですけど。
004 航：何が入ってたの？
005 高木：スーツ用の革靴です。来月から就活のイベントが始まるんで、バイト代でちょっといいのを買ったんですけど……。
006 キミ：おはようございます。あら、高木さん、ゆうべのお荷物、まだ見つからないの？
007 高木：はい……すみません、朝から騒がしくして。
008 キミ：いいのよ。でも困ったわねえ。うちの玄関でこんなこと、今までなかったのに。そういえば今朝のニュースで、トラックの運転手さんの残業が、今月から制限されるって言っていましたよ。
009 航：「物流の2024年問題」ですね。荷物を運ぶ人が足りなくなるかもしれない、って話です。……高木くん、とりあえず配送会社に問い合わせてみて。僕も帰ってきたら一緒に考えるから。
010 高木：はい、お願いします。……うわ、やばい、もうこんな時間だ。一限に遅れる！　すみません、行ってきます！

## ② 日常

【場面：杉並区役所・くらしの相談窓口／4月2日 午前10時】

011 美咲：早瀬さん、昨日の柳田さんの件、どうなりました？
012 航：うん、今朝、警察の相談窓口に電話して、番号を伝えておいたよ。あの後は、もうかかってきてないって。柳田さん、今朝はパンジーに「ありがとね」って話しかけてたよ。
013 美咲：よかったー。録音機、効果エグいっすね。
014 グエン：小野寺さん、「エグい」は、いい意味ですか、悪い意味ですか。
015 美咲：あ、今のはいい意味です。「すごい」って感じ。
016 グエン：なるほど。辞書には「えぐい味」の「えぐい」と書いてありました。苦くて、のどがいがいがする味だそうです。
017 航：若い人の言葉は、辞書が追いつかないからね。……あ、ところで小野寺さん、置き配の荷物がなくなったとき、どうすればいいか知ってる？
018 美咲：え、盗まれたんですか？
019 航：まだわからない。うちのアパートの大学生の子なんだけど、玄関に置いたってメールは来てるのに、荷物がないんだ。
020 美咲：あー、SNSでもたまに見ますよ。「置き配、盗まれた」って、空っぽの玄関の写真つきで。だから私、絶対置き配にしないです。
021 グエン：私は、置き配は便利だと思います。仕事の日は、家にいませんから。再配達をお願いするのも、なんだか申し訳なくて。
022 美咲：わかりますけど、私、推しのグッズが届くとき、もし盗まれたら立ち直れないんで。毎回コンビニ受け取りです。
023 航：なるほどね。受け取り方も、人によっていろいろだ。
024 大森：早瀬くん、それは窓口の相談案件かね。それとも世間話かね。
025 航：あ、すみません。今のところ、世間話です。
026 大森：ふむ。まあ、世間話から相談が始まることもあるからね。
027 美咲：課長、今日なんか優しくないですか。
028 大森：私はいつも優しいよ、小野寺くん。顔に出ないだけだ。……はい、次の方、どうぞ。
029 住民：すみません、転入届を出したいんですけど、ここで合ってますか。
030 航：いらっしゃいませ。転入のお手続きは、一階の区民課の窓口になります。よろしければ、そちらまでご案内いたしますね。

## ③ 問題発生

【場面：柳田荘の玄関／4月6日（土）夕方5時】

031 中川：あの、早瀬さん、ちょっといいですか。
032 航：あ、中川さん。どうしたんですか、そんな顔して。
033 中川：私の荷物もなくなったんです。お昼に「置き配完了」って通知が来たのに、さっき帰ってきたら、どこにもないんですよ。
034 航：中川さんもですか……。何が入っていたんですか。
035 中川：電気ケトルです。引っ越しのときに壊れちゃって、やっと買い直したのに。しかも、これ二回目なんです。
036 航：二回目？
037 中川：先月も一回、化粧品の小さい箱がなくなってて。そのときは、私の勘違いかなと思って黙ってたんですけど。
038 高木：え、中川さんも？　俺だけじゃなかったんだ。
039 中川：……高木くん、ちょっと聞いていい？　夜、よくお友だち来てるよね。玄関の前で、遅くまで話してる人たち。
040 高木：来てますけど……え、それ、どういう意味ですか。
041 中川：別に疑ってるわけじゃないけど、知らない人が出入りしてると、やっぱり気になるっていうか。
042 高木：いや、それ完全に疑ってますよね？　俺の友だち、人の荷物なんか取りませんよ。だいたい、俺の靴だってなくなってるんですから。
043 航：ちょっと待ってください、二人とも。まずは、落ち着いて……。
044 翔：ちわーっす、お届けものでーす。……あれ、なんか取り込み中っすか。
045 中川：あ、配達の方。ちょうどよかった。今日のお昼、ここに荷物を置いたの、あなたですか？
046 翔：はい、この辺は俺の担当なんで。ちゃんと置きましたよ。写真も撮って送ってますし。
047 中川：でも、ないんです。本当にここに置きました？　ほかの家と間違えたとか。
048 翔：いや、俺、一日に百五十個以上運んでるんすよ。一個一個、間違えないように必死でやってますって。こっちだって、雨の日も時間指定に追われながら走ってるんすから。
049 キミ：まあまあ、どうなさったの、皆さん。玄関で大きな声を出して……。
050 翔：……すんません、次の配達あるんで。失礼しまーす。

## ④ 調べる・相談

【場面：杉並区役所・くらしの相談窓口／4月8日（月）昼休み】

051 航：……っていうことがあってさ。週末、アパートの空気が最悪なんだ。
052 美咲：うわー、住民同士の疑い合いって、一番しんどいやつですね。
053 グエン：早瀬さん、まず警察に届けを出したほうがいいと思います。盗まれたのなら、それは犯罪ですから。
054 航：そうですね。中川さんには、交番で被害届を出せるって伝えるつもりです。置き配の写真があれば、それも持っていったほうがいい。
055 美咲：あと、通販サイトによっては、置き配で盗まれても補償されないことがあるんですよ。自分で置き配を選んだ、っていう扱いになるんで。
056 航：そうなんだ。じゃあ、まずは販売店と配送会社、両方に連絡だね。
057 大森：アパートの防犯なら、大家さんの協力が要るだろう。防犯カメラとか、宅配ボックスとか。
058 航：はい。宅配ボックスって、後から置けるタイプもありますよね。
059 美咲：ありますあります。玄関の横に置くだけの箱とか、折りたたみの袋みたいなやつとか。数千円くらいからあって、ちゃんとしたのは何万円もしますけど。アパート用に、部屋の数だけ箱が並んでるタイプもありますね。
060 グエン：でも、早瀬さん。お話を聞いていると、荷物の問題より、人と人の問題のほうが大きいように聞こえます。
061 航：……そうなんですよね。高木くんも中川さんも、悪い人じゃないんです。配達の人も、なんか、すごく疲れてる感じだったし。
062 大森：早瀬くん、最初の日に私が言ったこと、覚えているかね。
063 航：「まずはマニュアルどおりに」、ですか。
064 大森：……それもあるが、窓口は区民の「困った」を最初に受け止める場所だ、と言ったんだ。誰が、何に困っているのか。まずはそこからだよ。
065 航：誰が、何に困っているのか……。はい。

【場面：柳田荘の前の路上／4月8日 夜7時半】

066 航：あの、すみません。土曜日に来てくださった、配達の方ですよね。
067 翔：あ……どうも。この前は、すんませんでした。ちょっと言い方、きつかったっすね。
068 航：いえ、こちらこそ。いきなり疑うようなことになって、すみませんでした。203号室の早瀬です。
069 翔：佐野っす。佐野翔。……正直、最近ちょっとカリカリしてて。
070 航：もしよかったら、とりあえず話を聞かせてもらえませんか。お急ぎでなければ、ですけど。
071 翔：……五分だけなら。俺、個人事業主なんすよ。軽バン一台で、荷物一個運んでいくら、っていう契約で。
072 航：一個いくら、ですか。じゃあ、再配達になると……。
073 翔：再配達しても、お金は一円も増えないっす。同じ荷物を二回運ぶだけ。ガソリン代も時間も、こっち持ちっす。しかも今月から、元請けの会社に「再配達をもっと減らせ」って言われてて。
074 航：四月から、トラックの運転手さんの残業時間に上限ができたって聞きました。
075 翔：あれは会社に雇われてるドライバーの話なんで、俺みたいな個人は対象外なんすけど……そのぶん、こっちに回ってくる荷物は増えるし、置き配でさっさと終わらせろって空気で。正直、先月より手取り、減ってます。

## ⑤ こじれる

【場面：同じ路上】

076 航：それは……大変ですね。
077 翔：だから、置き配で盗まれたって言われると、マジで焦るんすよ。クレームが何回か入ったら、契約切られるかもしれないんで。
078 航：そうだったんですね。……佐野さん、もしよければ、先週の月曜日、四月一日の配達の写真って、まだ残っていますか。二階の高木くんの荷物なんですけど。
079 翔：一日っすか。ちょっと待ってください……あった、これっす。夜八時過ぎ。
080 航：……あれ？　佐野さん、このドア、緑色ですね。
081 翔：え？
082 航：柳田荘の玄関は、茶色い木のドアなんです。緑のドアって……隣の「コーポ松原」じゃないですか。
083 翔：……うわ、マジだ。あの日、暗くて、時間に追われてて……。番地が同じなんすよ、この二つのアパート。
084 航：ああ、確かに。住所の最後の号数が一つ違うだけなんですよね。
085 翔：やっべ……。これ、完全に俺のミスじゃないっすか。どうしよう、また会社に何て言われるか……。
086 航：佐野さん、落ち着いてください。まずは、隣に荷物が残っているかどうかですよね。僕は一階の大家さんの部屋にいますから。
087 翔：……行ってきます。今すぐ。

【場面：柳田荘・101号室（キミの部屋）／同じ夜 8時】

088 中川：柳田さん、お呼びいただいてありがとうございます。でも、はっきり言わせてください。防犯カメラをつけていただけませんか。こんなことが続くなら、私、正直、引っ越しも考えます。
089 キミ：カメラ……。そういうものは、お高いんでしょう？　それに、店子さんたちを機械で見張るみたいで、私、どうも気が進まなくて……。
090 高木：中川さん、まだ俺の友だちのこと疑ってるんですか。
091 中川：疑ってるとかじゃなくて、安心したいだけ。高木くんにはわからないかもしれないけど、一人暮らしの女性って、知らない人が夜に玄関にいるだけで怖いの。ケトルなんて、どうでもいいの。誰かが私の部屋の前まで来て、何か持っていったかもしれないって思うのが、嫌なの。
092 高木：……それは、わかりますけど。
093 キミ：ねえ、皆さん。うちは小さなアパートだけれど、主人がいた頃から、みんなで仲良くやってきたのよ。それが、こんなふうになるなんて……。お互いに顔も見ないで、疑い合うなんて、私、悲しいわ。
094 航：柳田さん……。
095 翔：夜分にすんません、失礼します！　あの、高木さんって、いらっしゃいますか。これ……隣のアパートの人が、預かっててくれました。

## ⑥ 解決

【場面：柳田荘・101号室】

096 高木：あっ、俺の靴！　え、なんで？
097 翔：一日の夜、俺が隣のアパートに置いちゃってたんです。番地が同じで……完全に俺のミスっす。本当に、すんませんでした！
098 高木：……マジか。盗まれたんじゃなかったんだ。
099 翔：隣の人、宛名が違うから、ずっと玄関の中に置いといてくれたみたいで。どこに返せばいいか、わかんなかったって。
100 中川：……じゃあ、高木くんの荷物は、誰も盗ってなかったんですね。高木くん、ごめん。お友だちのこと、勝手に疑って。
101 高木：いや……俺も、配達の人のせいだって、心のどこかで思ってました。佐野さん、すみません。
102 翔：いやいや、俺が間違えたんで。頭上げてください。
103 航：でも、中川さんのケトルは、まだ見つかっていないんですよね。
104 中川：はい。写真では、ちゃんとこの玄関に置いてあるんです。
105 航：じゃあ、そちらは明日、交番に被害届を出しましょう。販売店にも写真を送って、事情を説明して。よかったら、交番まで一緒に行きますよ。盗まれたかどうかはっきりしなくても、届けておけば、同じことが続いたときに警察も動きやすくなりますから。
106 キミ：……早瀬さん。カメラはもう少し考えさせてほしいけれど、その、宅配ボックス、っていうのは、どうかしら。
107 航：いいと思います。玄関の横に置くタイプなら工事もいりませんし、鍵がかかるので、ただの置き配よりずっと安心です。
108 翔：ボックスがあると、マジで助かるっす。留守でも一回で終わるんで。
109 航：それと、柳田荘の住民で、グループチャットを作りませんか。ルールはシンプルに。「置き配はボックスか、日時指定で」「人の荷物を預かったら、チャットで知らせる」。それから、「知らない人を見かけたら、責める前に共有する」。
110 高木：いいですね、それ。俺、作ります。柳田さんも入れるように、使い方教えますよ。
111 中川：あと一つ、足していいですか。「疑う前に、まず聞く」。……自分への反省も込めて。
112 キミ：まあ、すてきなルールですこと。主人が聞いたら、きっと喜びますわ。

## ⑦ エピローグ

114 航：お疲れさまです、佐野さん。中川さん、販売店がケトルを送り直してくれることになったそうですよ。交番にも届けたので、何かわかったら連絡が来ます。
115 翔：よかったー。……早瀬さん、俺、昨日、このへんの再配達ゼロだったんすよ。初めて。
116 航：本当ですか。それはよかったです。

【場面：阿佐ヶ谷・町中華「福来軒」／同じ日 夜9時】

117 大輔：らっしゃい！　おう、航。アパートの荷物の件、片づいたんだって？
118 航：なんとかね。半分は配達のミスで、もう半分はまだ交番の結果待ち。……大輔、そのカウンターの紙、何？
119 大輔：「値上げのお知らせ」。来月から、ラーメン七百五十円を八百五十円にする。……なあ、航。これ、常連さんにどう説明したらいいと思う？
120 航：……とりあえず、話聞こうか。

## 어휘·표현 노트

| 표현 | 읽기 | 뜻 | 비고 |
|---|---|---|---|
| 置き配 | おきはい | 문 앞 비대면 배송 | 置き配完了 = 배송 완료 알림 |
| 再配達 | さいはいたつ | 재배달 | 부재 시 다시 배달하는 것. 2024년 문제의 핵심 키워드 |
| 物流の2024年問題 | ぶつりゅうのにせんにじゅうよねんもんだい | 물류 2024년 문제 | 운전사 시간외 노동 상한 적용에 따른 운송력 부족 |
| 一限 | いちげん | (대학) 1교시 | 一限に遅れる |
| エグい | | (젊은이 말) 대단하다 / 심하다 | 원래 えぐい = 아리다. 표준적 대응: すごい・ひどい |
| 世間話 | せけんばなし | 잡담, 세상 이야기 | |
| 取り込み中 | とりこみちゅう | 경황이 없는 중, 바쁜 중 | お取り込み中すみません |
| 被害届 | ひがいとどけ | 피해 신고서 | 交番·警察署에 제출 |
| 補償 | ほしょう | 보상 | 置き配 도난은 보상되지 않는 경우도 |
| 宅配ボックス | たくはいボックス | 택배 보관함 | 後付け(나중에 설치) 置き型 타입 |
| 個人事業主 | こじんじぎょうぬし | 개인사업자 | 軽貨物 기사의 많은 수가 이 형태 |
| 元請け | もとうけ | 원청 (회사) | ↔ 下請け 하청 |
| 手取り | てどり | 실수령액 | |
| カリカリする | | 신경이 곤두서다, 짜증 나다 | イライラする와 비슷 |
| 番地 | ばんち | 번지 | 같은 번지에 건물이 여럿 있는 경우가 많다 |
| 店子 | たなこ | 세입자 | 옛말. 현대어는 入居者・住人 |

### 말투 포인트
- **翔의 「〜っす」체**: 「ちわーっす」「マジっすか」「すんません」은 「こんにちは」「本当ですか」「すみません」의 운동부·현장 계열 캐주얼 정중체. 손님 앞에서도 완전한 경어로 바꾸지 않는 것이 캐릭터의 특징.
- **경어 단계 대비**: 航은 창구에서 「〜の窓口になります」「ご案内いたしますね」(업무 경어), 처음 만난 翔에게 「〜てもらえませんか」「お急ぎでなければ」(정중어), 高木에게 「見た？」「〜てみて」(손위 이웃의 반말), 大輔에게 「なんとかね」「話聞こうか」(친구 반말). 같은 「とりあえず話を聞く」도 「話を聞かせてもらえませんか」 ↔ 「話聞こうか」로 달라진다.
- **완곡한 비난과 직설**: 中川의 「別に疑ってるわけじゃないけど、〜っていうか」는 돌려 말하는 비난. 高木가 「それ完全に疑ってますよね？」로 받아치는 구조가 일상 갈등 회화의 전형.
- **キミ의 말씨**: 「〜ですこと」「〜ますわ」「お高いんでしょう」는 옛 山の手 여성어. 현대 표준어로는 「すてきなルールですね」「喜ぶと思います」「高いですよね」.
- **美咲의 젊은이 말 해설**: 「エグい」를 グエン에게 「すごいって感じ」로 바꿔 주는 장면 ― 같은 말이 좋은 뜻·나쁜 뜻 양쪽으로 쓰인다.

### 이번 화의 현안 메모
- 2024년 4월부터 트럭 운전사에게 시간외 노동 상한(연 960시간)이 적용되면서 「운송력이 부족해진다」는 「物流の2024年問題」가 화제가 되었다. 정부는 재배달을 줄이는 것을 대책의 하나로 내세우고 置き配·宅配ボックス·コンビニ受け取り 이용을 권장했다.
- 택배의 「마지막 1마일」은 개인사업자인 軽貨物 기사가 건당 단가로 맡는 경우가 많다. 이들은 노동시간 규제의 직접 대상이 아니지만, 재배달 감축 압박과 물량 변동의 영향을 고스란히 받는다.
