# 대본 집필 가이드 ― 『となりの窓口』 (모든 화 공통)

설정: `tonari/plan/00_series_bible.md`, `tonari/plan/0N_partN.md`

## 파일
- 경로: `tonari/script/partN/epXX.md` (N = 1~4, XX = 01~15)
- 각 부 폴더에 `CONTINUITY.md`를 두고 한 화를 마칠 때마다 갱신:
  새 인물(이름·읽기·나이·말투), 확정된 사실(날짜·금액·장소), 남은 복선, 다음 화로 넘긴 한마디.

## 형식
1. 제목: `# 第N部 『부 제목』 第X話 「화 제목」（한국어 제목）`
2. 정보 표: 턴 수(120) / 시기(年月) / 등장인물 / 구성(7구간과 턴 범위) / 반영 현안
3. 본문: `## ① オープニング` … `## ⑦ エピローグ`, 구간 사이에 `---`
4. 장면 표시: `【場面：場所／時間】`
5. 대사: `NNN 話者：台詞` (NNN = 001~120, 한 줄에 한 턴, 빠짐·중복 없이 정확히 120턴)
   - 화자 표기는 이름(航·遥·大輔·美咲·グエン·キミ·源三 등) 또는 역할(住民A、店員、警察官).
   - 지문·내레이션 없음. 행동·감정은 대사로 드러낸다.
6. 마지막에
   - `## 어휘·표현 노트` (표, 12~16개: 표현 / 읽기 / 뜻 / 비고)
   - `### 말투 포인트` (3~5개 불릿: 경어 단계, 방언→표준어 대응, 젊은이 말 등)
   - `### 이번 화의 현안 메모` (2~3줄, 한국어로 실제 제도·사건 배경)

## 120턴 7구간 (±5턴 조정 가능)
① オープニング 1–10 / ② 日常 11–30 / ③ 問題発生 31–50 / ④ 調べる・相談 51–75 / ⑤ こじれる 76–95 / ⑥ 解決 96–112 / ⑦ エピローグ 113–120
- 120번째 턴은 여운 또는 다음 화로 이어지는 한마디(질문·소식·혼잣말).
- 앞 화 엔딩의 한마디를 다음 화 オープニング이나 日常에서 받는다.

## 내용 원칙
- 1화 1문제. 해결은 「완벽」보다 「조금 나아짐」. 악역을 만들지 않는다.
- 문제는 반드시 그 시기의 실제 현안과 연결하되, 뉴스 해설이 아니라 생활의 장면으로 보여 준다.
- 제도·날짜·금액은 실제에 맞춘다. 불확실하면 숫자를 피하고 「去年より倍近く」처럼 쓴다.
- 실존 정치인·유명인·기업명 금지. 정치 쟁점은 여러 인물의 다른 의견으로 두고 결론을 강요하지 않는다.
- 일본어는 **수도권 표준어** 기준. 방언·젊은이 말·외국인 일본어는 인물 설정 범위에서만, 노트에서 표준어 대응형을 보여 준다.
- 한 화 안에 경어 단계 대비(창구 경어 ↔ 친구 반말 등)가 최소 한 번은 나오게 한다.
- 분량: 본문 대사 약 5,000~7,000자.

